## 1. 背景与诉求

v0.7.0（搜索与离线）交付后，需求方要求「继续规划」。路线图 v0.8 原列三项：汉字笔顺动画、多龄段模式、拼音自动标注。逐项核查现状后，发现三件事：

| 核查项 | 现状 | 问题 |
| --- | --- | --- |
| 分龄 | 首页 22 个分类平铺，809 张卡不分年龄 | 1 岁孩子与 5 岁孩子看到**完全一样**的一份内容；「蔬菜」「海洋动物」「小虫子」「职业」「穿戴」对 1 岁偏难，却没有退路 |
| `difficulty` 字段 | v0.1 就写进模型与种子（实物卡 1/2/3 = 58/115/64，汉字 92/150/79，古诗 12/21/17，故事 15/31/4，成语 23/58/69） | **前台从未读取过它**：全库只有仓储写入与种子赋值。数据标好了却在睡觉，缺的只是一个消费它的出口 |
| 拼音录入 | 家长建卡必须自己敲带声调字母（`ǎ` `ǒ` `ǚ`），手机键盘要长按才能出 | 录入摩擦大；而 `AGENT.md` §6 已定「**拼音不做自动生成**：多音字错误比缺失更糟」，所以不能直接静默生成 |
| 笔顺动画 | `Card` 只有 `strokes: number`（如「人 2 画」），**没有任何笔顺路径数据** | 321 字要逐笔演示必须引入外部笔顺字形数据（估算 400–800 KB）+ 按组切片懒加载，属重管线工程，与分龄、拼音混装会互相拖累验收 |

本版因此**只做前两项**：把已经躺在数据里的 `difficulty` 接出来做分龄，把拼音录入从「硬敲」变成「点选」。笔顺动画的数据口径已定（321 字全覆盖 + 8 组切片），单列 **v0.8.1** 交付。

## 2. 需求条目

| 编号 | 需求 | 说明 |
| --- | --- | --- |
| US-W1 | 首页分龄入口 | 分类墙**上方**新增两张大卡：「1–3 岁 · 启蒙」与「3–6 岁 · 进阶」，各显示适龄张数与一句说明；分类墙本身行为完全不变 |
| US-W2 | 分龄浏览区 | 新增 `/age/:band`（`1-3` / `3-6`）：该龄段的分类墙，每个分类角标显示**适龄张数**；适龄 0 张的分类不出现 |
| US-W3 | 分类内按龄筛选 | 从分龄区进分类带 `?band=`：只显示适龄卡，顶栏标注「1–3 岁 · 6 / 13 张」并给「看全部」；分页基于筛选后的集合 |
| US-W4 | 详情页跟随 | 带 `?band=` 进入详情后，上一张 / 下一张只在**当前龄段序列**内翻；返回回到带 `?band=` 与页码的原列表 |
| US-W5 | 拼音候选 | 管理区卡片表单：输入中文后按字列出候选读音（多音字列出**全部**读音），家长点选后拼成带声调拼音填入；不点选不写入，已手输的内容不被覆盖 |
| US-W6 | 不做破坏性变更 | 复用 `difficulty` 而不加字段、不改 `schemaVersion` / `SEED_VERSION`、不引运行时拼音库、既有路由语义（除新增 `/age/:band`）不变 |

## 4. 本版不做

1. **不做笔顺动画**：数据口径已定（外部笔顺字形数据、321 字全覆盖、按汉字 8 个主题组切片懒加载），单列 v0.8.1，不与分龄混装。
2. **不重新标定 `difficulty` 数值**：沿用 v0.1–v0.6 已标注的值，本版只消费、不修改；将来若要重标，走种子版本升级（`SEED_VERSION` 10），不混在本版。
3. **不给收藏 / 最近 / 复习 / 听音选图 / 搜索加龄段过滤**：它们各有自己的顺序语义（收藏是孩子点的、复习按「不认识」、听音选图按难度升序），加龄段过滤会打乱既有验收。
4. **不做家长自定义龄段**：固定两档，避免「自定义 → 内容分档解释不清」。
5. **不做拼音整词智能识别**：只做「按字候选」，不做「猜整词读音」。多音字组合会爆炸（4 字词最多 16 种），猜错就是家长直接信任错音。
6. **不改管理区之外的拼音输入**：导入 JSON、种子内容、批量操作一律不碰。

## 5. 待确认口径

> 2026-10-31 需求方确认：三条口径全部按建议取值（D-W1 难度 2 重叠带、D-W2 分类墙上方两张并排、D-W3 `pinyin-pro` 仅作 devDependency 构建期生成）。

| 编号 | 口径 | 建议取值 | 理由 |
| --- | --- | --- | --- |
| D-W1 | 龄段 ↔ `difficulty` 映射 | 1–3 岁 = 难度 1 + 2；3–6 岁 = 难度 2 + 3（**难度 2 为重叠带**） | 若 1–3 岁只取难度 1，则蔬菜 / 海洋动物 / 小虫子 / 职业 / 穿戴 **5 个分类为 0 张**，分龄分类墙会出现空分类；并入难度 2 后 18 个分类全部非空（58 → 173 张） |
| D-W2 | 分龄入口位置 | 分类墙**上方**（首屏第一行两张并排，窄屏上下堆叠），不占顶栏 | 顶栏已承载标题 / 入口条 / 搜索 / 源码 / 语言，再塞两档会挤；且分龄是「选择入口」不是「全局开关」 |
| D-W3 | 拼音候选数据来源 | `pinyin-pro`（MIT）作 **devDependency**，由脚本在构建期生成精简字典；运行时**零新依赖** | 与 `prepare:images` / `prepare:audio` 同一套「脚本生成产物、运行时只读」的模式；避免 134 KB（gzip）的运行时库进包 |
