## 1. 需求背景与目标

### 1.1 背景

两件事把这一版逼出来：

1. **v0.3.3 的发音修复只做到「不再沉默」，没做到「一定能出声」。** 现场取证结果是：设备上英文音色**全是网络音色（本地 0 个）**，连不通厂商服务器时，代码层面重试、换音色、提示都做了，孩子听到的仍然是安静。应用已部署、客户端不可控——不能要求每个家长去系统设置里加装语音包。**要让英文「点了必出声」，只有一条路：把英文发音做成应用自带的静态资源。**
2. **现在的产品是一本可编辑的电子图册，没有反馈回路。** 501 张卡能看、能听、能改，但孩子看过什么、哪些已经认识、哪些还生——一律不记得，也没有任何「练一遍」的形态。早教产品和图册的分水岭恰好在这里。

### 1.2 目标

| 目标 | 衡量方式 |
| --- | --- |
| G1 英文点了必出声 | 任意设备（含零本地英文音色的设备）点 English，≤ 400ms 听到发音；音频缺失时才回退 TTS，仍失败必须 Toast 说明原因 |
| G2 发音可替换可核对 | 每条音频按卡片 id 固定命名，同名文件即可替换为真人录音；内容门禁能校验 501 条齐全 |
| G3 看过什么留得下痕 | 浏览过「最近浏览」，收藏的卡在「我的收藏」里能一屏找到 |
| G4 认识与否由家长/孩子标记 | 详情页一次点击即可完成「认识 / 不认识」标记，标记在设备上持久保存 |
| G5 生疏的能再练一遍 | 复习入口显示待练数量，进入后只出不认识的卡，标「认识」即移出队列 |
| G6 能玩 | 听音选图一局 10 题，纯点选、不识字也能玩；无发音可用时明确不可开局而不是白屏 |
| G7 与既有能力一致 | 展示模式、语速、只读模式、导入导出、家长门全部复用，不重复造轮子 |

### 1.3 决策变更：为什么现在开「学习轨迹」这个口子

`FR/v0.1/PRD.md` 把「记录学习轨迹」列入不做，`FR/v0.2/PRD-故事绘本.md` §6 进一步明确「阅读进度记忆 / 书架不开口子」。本版**推翻这两条**，理由与边界如下：

| 当时不做的理由 | 现在为什么可以做 |
| --- | --- |
| 会引入账号与数据归属问题 | 进度**只存本机 localStorage**，不进导出包、不上传、可一键清除，无账号也无跨设备语义 |
| 幼儿没有「学习进度」概念 | 标记与复习的操作主体是**家长带孩子**一起点，产品形态上是家长工具而非孩子自律工具 |
| 容易滑向刷题与攀比 | 本版明确不做分数、排行、连击奖励、每日任务（见 §6），复习与游戏都是「玩一遍」的量级 |

> 这是一次**受控的范围扩张**：只记三件事——收藏、最近看过、认识/不认识。除此之外不留痕。

### 1.4 版本主题拆分（交付顺序）

## 2. 用户故事与验收标准

### US-E1 英文点了必出声（P0）

作为家长，我希望在任何设备上点 English 都能听到发音，以便不用先研究怎么装系统语音包。

- Given 内置卡片（有对应音频文件），When 点 English，Then 播放的是**自带音频**，与设备有没有英文音色无关。
- Given 设备无任何本地英文音色且音频文件存在，Then 仍然出声（本用例即 v0.3.3 现场环境的根治）。
- Given 音频文件不存在（家长自建卡、或资源缺失），Then 自动回退到设备 TTS 链路（沿用 v0.3.3 的本地音色优先 + 1.5s 静默看门狗 + 最多换 3 个音色）。
- Given 音频与 TTS 都失败，Then Toast 说明具体原因，不得「点了什么反应都没有」（沿用 v0.3.3 的 US-04 约束）。
- Given 中文朗读，Then 行为不变（仍走设备 TTS，本机有 3 个本地中文音色，已验证正常）。

### US-E2 语速与音量跟随设置（P1）

作为家长，我希望把语速调慢时英文也一起变慢，以便孩子跟得上。

- Given 设置语速为 0.6，When 播放自带音频，Then 以 `0.6` 倍速播放（听感明显变慢、不破音）。
- Given 语速 1.2，Then 1.2 倍速播放。
- Given 播放中再次点同一个按钮，Then 停止当前并重新播放（与 TTS 一致的重入语义）。
- Given 点「停止朗读」，Then 音频立即停，且连播模式不自动跳下一张。

### US-A1 收藏（P0）

作为家长，我希望把孩子最近反复要看的那几张卡收起来，以便不用每次都翻分类找。

- Given 在卡片详情页，Then 有一个收藏按钮（心形），当前状态明确可读（已收藏 / 未收藏），触控高度 ≥ 48px。
- Given 点收藏，Then 立即生效（无需确认弹窗），Toast 提示「已加入收藏 / 已取消收藏」。
- Given 在分类页卡片墙上，Then **不出现**收藏按钮（防幼儿乱点，收藏只从详情页发起）。
- Given 首页，Then 有「我的收藏」入口并显示数量；点进 `/favorites` 以卡片墙形式展示全部收藏，点任一张进入详情。
- Given 收藏为空，Then `/favorites` 显示空态与「去逛逛」按钮，不显示空白网格。
- Given 收藏的卡被家长在管理区删除，Then 该 id 自动从收藏中移除，不出现「点不开的破卡片」。

### US-A2 最近浏览（P1）

作为家长，我希望接着上次的位置继续，以便孩子说「还要看那个」时能找到。

- Given 进入任意卡片详情或故事页，Then 记入「最近浏览」，同一张卡重复进入只更新一条（不堆重复项）。
- Given 最近浏览最多保留 **24 条**，超出时最旧的被淘汰。
- Given 首页，Then 「接着看」区横向展示最近 8 张，点任一张进入；无记录时该区整体不显示（不留空壳）。
- Given 从「最近浏览」进入详情后返回，Then 回首页，不出现返回栈循环。

### US-A3 认识 / 不认识标记（P0）

作为家长，我想知道孩子哪些字已经认识、哪些还不熟，以便安排复习。

- Given 详情页，Then 有「认识」「不认识」两个并排大按钮；当前标记高亮，未标记时两者都呈未选中态。
- Given 点「认识」，Then 标记为认识；再点一次**取消标记**（回到未标记），不出现「只能变好不能变差」。
- Given 从「不认识」改点「认识」，Then 直接切换，不弹二次确认。
- Given 只读模式（存储不可用），Then 按钮可点但仅本次会话有效，并提示「本机存储不可用，标记不会保存」。
- Given 首页，Then 显示统计一句话：「已标记 N 张 · 其中 M 张还不熟」（N=0 时改为引导文案，不显示 0 的空统计）。

### US-A4 复习队列（P1）

作为家长，我希望带孩子只练不熟的那几张，以便不必从头再刷 501 张。

- Given 点首页「练一练不熟的（M）」，When M > 0，Then 进入 `/review`，一次只显示一张卡（大图 + 中英 + 上/下一张），顶部显示「第 x / M 张」。
- Given 复习中点「认识了」，Then 该卡标记改为认识、移出队列、自动到下一张；队列清空时显示完成态「这些都认识啦」+ 返回首页。
- Given 复习中点「还不熟」，Then 保持不认识、直接到下一张，**不做任何负面提示**（无叉、无错音、无红框）。
- Given M = 0 时进入 `/review`（含直接敲 URL），Then 显示空态「还没有标记不熟的卡片」，并引导去卡片墙点「不认识」。
- Given 每轮复习最多 **10 张**（幼儿注意力短），超出时提示「今天先到这儿」并结束本轮，剩余留到下次。

### US-A5 听音选图（P1）

作为幼儿，我希望玩「听一个词、指一张图」的游戏。

- Given 点首页「听音选图」，Then 进入 `/quiz`，显示 4 张大图选项与一个「再听一遍」按钮，**题目语音自动播一次**。
- Given 4 个选项，Then 1 个正确 + 3 个干扰；干扰**优先从同一分类取**（同分类不足 3 张时从全库补齐），选项位置随机。
- Given 点对的图，Then 播放该卡发音作为正反馈并进入下一题；连对计数只在本局内存，不写存储。
- Given 点错的图，Then 高亮正确的那张并播它的发音，同一题可再选一次（不判负、不扣分、不出叉）。
- Given 一局 10 题完成后，Then 显示「这一局玩完啦」+「再来一局」「返回首页」；不显示分数百分比与名次。
- Given 设备既无可用英文音频又无任何可出声的音色，Then 不进入题目，显示「这台设备的发音用不了，先在系统里加装英文语音」，**不出现白屏与死循环**。
- Given 汉字卡（`kind=character`），Then 读的是英文词还是汉字由模式决定：默认**中文出题**（读汉字，玩认字），英文出题需在开局前选择（见 §3）。

### US-A6 详情页连播（P1）

作为家长，我希望放着让它自己翻，以便孩子自己看。

- Given 详情页工具栏有「连播」开关，点开启，Then 朗读当前卡 → 停顿 **2s** → 自动下一张 → 继续朗读，直到该分类（或当前分组页）最后一张。
- Given 播到末尾，Then 停止并 Toast「这一组看完啦」，**不自动循环**（幼儿会一直看下去）。
- Given 连播中点「停止」/ 手动翻页 / 切到别的页面 / 应用切到后台，Then 连播立即停止，恢复后不自动续播。
- Given 朗读失败（发音不可用），Then 连播停止并提示原因，不出现「静默地一张张跳过」的诡异效果。
- Given 「减少动效」开启，Then 翻页仍淡入淡出以外效果关闭，连播功能不受影响。

### US-A7 家长使用说明（P2）

作为新家长，我想知道这应用能干什么、孩子点不动的地方在哪。

- Given 首页底部有「给家长的使用说明」，When 进入 `/guide`，Then 一页说清：分类怎么用、点读怎么发音、家长门怎么进（长按 3 秒 + 算题）、怎么自己加卡片、导出备份怎么做、发音没声时怎么办（引设置页「本机音色」那一行）。
- Given 说明页每个条目 ≤ 3 行，Then 无长段落墙；含一条「标记和收藏只存在这台设备上，清空浏览器数据会没有」。
- Given 说明页，Then 不出现任何管理操作按钮（避免幼儿点到能进管理区的入口）。

## 3. 交互与视觉约束

| 约束 | 说明 |
| --- | --- |
| 孩子可用的入口 | 收藏、认识/不认识、复习、听音选图、连播均**不加家长门**——这些是给孩子点的；只有「清除进度」需要家长门 |
| 按钮尺寸 | 详情页新增按钮（收藏 / 认识 / 不认识 / 连播）触控高度 ≥ 48px，图标 ≥ 24px，符合幼儿手指精度 |
| 布局位置 | 详情页工具栏区：返回与翻页在上，朗读按钮居中，收藏 + 认识 / 不认识 在下成一行；不挤掉原有大图占比（图片区仍为视觉主体） |
| 无负面反馈 | 复习与游戏中答错不得出现红叉、错误音、震动、扣分动画；只给正向（播正确发音 + 高亮正确图） |
| 首页信息密度 | 新增内容只允许三块：顶部「我的收藏 / 练一练 / 听音选图」入口条、「接着看」横滑区、底部统计与说明链接；分类墙仍是主体，不得被挤到两屏以外 |
| 出题语言 | 听音选图开局前只两个选择：认汉字 / 认英文，默认认汉字（1–3 岁先认图与中文更实际） |
| 进度不入导出 | 收藏、标记、最近浏览**不进 `ExportBundle`**，导入/替换内容不影响进度；导出仅内容本身 |
| 隐私 | 全部数据留在本机 localStorage，无网络上报、无埋点、无统计脚本 |
| 动效 | 复用现有 `--motion-fast` 淡入；复习/游戏的正确高亮用色不用图标动画；尊重「减少动效」 |
| 可访问性 | 所有新按钮带 `aria-label` 与 `aria-pressed`（与现有 `aria-pressed` 用法一致）；游戏选项用按钮而非图片裸点 |
| 安全区 | 新增底部按钮行须留 `--safe-b`，小屏不遮挡 |

## 4. 数据与内容规范

### 4.1 英文音频资源

| 项 | 口径 |
| --- | --- |
| 覆盖范围 | 全部 **501 张内置种子卡**各一条（`object` / `character` / `poem` / `story`，`en` 均 ≤ 3 词，实测平均 1.31 词）；家长自建卡**不生成**，走 TTS 回退 |
| 路径约定 | `assets/audio/{cardId}.mp3`（与卡片 id 一一对应，如 `assets/audio/animals-cat.mp3`），`Card.image` 与卡片字段不变 |
| 编码 | mp3 / 单声道 / 22.05kHz / 32kbps；单条 ≤ 12KB，全量目标 **≤ 4MB** |
| 时长 | 0.4–3.0s；超 3s 视为异常（多为空文本或标点串），内容门禁报错 |
| 可替换性 | 真人录音**同名覆盖即可生效**，无需改代码（与 ADR-005 图片「同名替换」策略同构） |
| 清单 | `assets/audio/manifest.json`：`{ cardId: file }` 映射；应用启动后**首次朗读英文时懒加载一次**，不在清单里的卡直接走 TTS |
| 生成方式 | `scripts/prepare-audio.mjs` 调本机 SAPI5 英文音色（`Microsoft Zira Desktop`）出 WAV，再用 ffmpeg 转 mp3；**已在本机验证跑通**（样例 `apple` 1.39s / 6.0KB） |

> **音质保有个明确预期**：本机离线能拿到的英文音色是系统 SAPI 合成声，清晰度足够、发音准确，但**不是真人**。这一版把它当「保证有声」的兜底，而非「最好听的发音」；后续逐条替换真人录音是本版设计好但不在本版执行的事。

### 4.2 进度数据（新增本地切片）

| 项 | 口径 |
| --- | --- |
| 存储键 | `early-learn:v1:progress`，`schemaVersion: 1` |
| 结构 | `{ schemaVersion, favorites: CardId[], recent: [{ cardId, at }], marks: { [cardId]: { status: 'known' \| 'unknown', at } } }` |
| 上限 | `favorites` 无上限（最多 501）；`recent` 最多 **24** 条；`marks` 无上限（键为现存卡片 id） |
| 体积估算 | 501 张全标 + 24 条最近 + 501 张收藏 ≈ 60KB，远低于 localStorage 配额；`STORAGE_WARN_BYTES`（3MB）告警机制沿用 |
| 容错 | JSON 解析失败或结构非法 → 视为空进度（全部功能可用，只是没记录），并在 `corrupted` 键留痕，与现有 catalog 容错策略一致 |
| 清理 | 卡片被删除 / 导入替换后，读取时对**已不存在的 id 自动剔除**（在仓储加载阶段做剪枝，不残留破引用） |
| 重置 | 管理区「重置」流程增加「清除学习进度」，需家长门；只清 `progress` 键，不动内容 |

### 4.3 复习与游戏的取数规则

| 规则 | 口径 |
| --- | --- |
| 复习队列 | `marks` 中 `status = 'unknown'` 的卡，按 `difficulty` 升序 → 同级随机；每轮上限 10 |
| 出题来源 | 听音选图默认从**已浏览过的卡**（`recent` ∪ `favorites` ∪ 已标记卡）出题；不足 10 张时从全库随机补（保证孩子没看过也能玩） |
| 干扰项 | 同分类优先，不足则全库随机补；同一局内不重复出同一道正确项 |
| 发音选择 | 出题语言为英文 → 走英文音频/TTS；为中文 → 走中文 TTS（本机有本地中文音色） |

## 5. 边界与异常

| 场景 | 处理 |
| --- | --- |
| 音频 404 / 解码失败 / `stalled` | 立即回退 TTS 链路；若 TTS 也失败按 v0.3.3 分类文案 Toast；不出现「点了没声」 |
| `assets/audio/manifest.json` 拉取失败（离线、路径变更） | 整站按「无音频」运行，全部走 TTS；不阻塞启动，不重复反复请求（一次失败即缓存结论） |
| 音频未加载完就被连点两次 | 打断当前播放重播（`pause + currentTime = 0`），不叠加两层声音 |
| 朗读中途切页 | 音频与 TTS 一并停止（沿用现有 `generation` 令牌语义） |
| 只读模式（localStorage 不可用） | 收藏/标记/最近浏览均可点但仅会话内有效，首次点击时提示一次「不会保存」；复习与游戏可用（取数为当次会话） |
| 无痕模式下写入抛配额异常 | 静默降级为会话内存储，不白屏、不报错刷屏 |
| 卡片被删除后其进度残留 | 加载时剪枝（§4.2），收藏、标记、最近浏览三处都清 |
| 导入 replace 模式覆盖内容 | 进度**保留**，但被删掉的卡按上述剪枝规则失效 |
| 复习队列中途标记变化 | 以实时 `marks` 为准，已出队列不影响当前索引；越界则回到队列末尾 |
| 游戏同分类只有 1 张卡 | 干扰项从全库补齐 3 个；全库不足 4 张（极端裁剪场景）则不开局并提示「卡片太少，玩不了」 |
| 发音完全不可用 | 游戏与连播在开局/开场前探测，明确提示不可用并给出加装本地语音的指引；复习不依赖发音仍可用（读图识字） |
| 页面切后台（连播中） | 立即停止，回前台不自动续播 |
| 幼儿连点收藏 20 次 | 状态幂等切换，Toast 合并为最后一条，不堆 20 层提示 |

## 6. 明确不做（Out of Scope · v0.4）

| 项 | 原因 |
| --- | --- |
| 真人录音采购 / 在线 TTS 服务 | 本版用本机离线合成；真人替换只需同名覆盖文件，属运营动作不属功能 |
| 中文自带音频 | 本机已有 3 个本地中文音色且验证正常，收益低于体积成本 |
| 账号、云同步、跨设备进度 | 与 v1.0「云端协同」一起讨论，本版刻意只留本机 |
| 分数、排行、连击奖励、每日任务、打卡 | 1–3 岁不需要，且会把产品推向刷题 |
| 自适应难度 / 推荐算法 / 遗忘曲线 | 复习只按「不认识」这一条硬规则，可解释、不神秘 |
| 学习周报 / 导出学习数据 | 隐私边界：进度不离开设备 |
| 给孩子看的入口加家长门 | 复习与游戏本就该孩子点；加了门反而挡住主用途 |
| 笔顺动画 / 多龄段模式 / PWA 离线 | 属 v0.5 内容与体验范畴，本版不掺进 |
| 家长上传照片自动压缩 | 属 v0.6 生产工具范畴（已单列为待办，不在本版夹带） |

## 7. 验收标准（DoD · v0.4）

- [x] 501 条内置英文音频齐备，单条 ≤ 12KB、时长 0.4–3.0s，全量 ≤ 4MB；`validate:content` 含音频齐全性与体积校验
- [x] 在**零本地英文音色**的设备上点 English 仍然出声（用设置页「本机音色：英文 …（本地 0 个）」那行复核）
- [x] 无音频的家长自建卡仍能朗读（TTS 回退路径未被打断）
- [x] 语速设置对自带音频生效（0.6 / 0.8 / 1.0 / 1.2 四档听感可辨）
- [x] 收藏、认识/不认识、最近浏览三个动作在详情页可完成，按钮 ≥ 48px，状态可读
- [x] 只读模式下三个动作不报错，并提示一次「不会保存」
- [x] 删除卡片后进度自动剪枝，收藏页与复习队列不出现点不开的破项
- [x] 复习：队列只出「不认识」，每轮 ≤ 10 张，标「认识了」即移出，空队列与 M=0 直连 URL 都有态
- [x] 听音选图：一局 10 题、四选一、干扰项同分类优先、答错无负面反馈、发音不可用时不开局
- [x] 连播：读完 2s 自动下一张，到末尾停止不循环，切后台/手动翻页/停止按钮都能立即中断
- [x] 首页仍保持「分类墙为主体」，新增三块内容不把它推出两屏
- [x] 进度不进 `ExportBundle`；导入导出不影响进度
