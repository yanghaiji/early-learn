## 1. 背景与问题（2026-11-01 v0.14 交付后三档 / 两档实拍复检）

### 关键事实：详情页的信息与功能不需要动，只重排视觉骨架

- 五类详情的**内容字段、朗读 / 收藏 / 认识 / 翻页 / 连播功能、路由与数据层全部保留**，本版只改「怎么摆」，不改「有什么」。
- 汉字卡的**笔顺播放器**（v0.9 落地的 `StrokePlayer`，321 字全覆盖、原位可播）本就是汉字卡最有价值的主视觉，只是当前被塞在右列小框里、左栏反让给了近乎空白的封面图——本版把它提到主位。
- 普通卡（object）、故事卡的封面图**观感良好**（`animals-cat` / `stories-three-pigs` 实拍），保持左图右文不动，问题只在 character / poem / idiom 三类。

## 3. 页面结构（精修点，功能与字段全部不动）

1. **汉字卡详情（N-1 / T-1）**：`kind === 'character'` 时，左栏 `.detail__stage` 直接渲染 `StrokePlayer`（升为主视觉、放大），**不再渲染那张近乎空白的封面 `<img>`**；右列 `.detail__words` 去掉重复的笔顺小框，只留拼音 + 组词 meta。无笔顺数据时（当前 321 字全覆盖，属兜底）左栏回落到大方块里的静态大字，同样不显示空白封面。
2. **成语卡 / 古诗卡详情（N-2 / N-3 / T-2）**：统一 ≥900 的两栏骨架——左栏主视觉与右栏文字块共享垂直居中基线；`actions`（朗读 / 学习 / 翻页）并入右栏内容流末尾，不再独占被 `1fr` 拉伸的独立行，消除「中文」按钮悬空。poem 译文左对齐、限制换行宽度。
3. **五类统一骨架（N-4 / T-2）**：普通卡 / 故事卡维持既有居中两栏（已协调）；汉字卡走「笔顺主视觉」新分支；poem / idiom 收敛到同一套「主视觉 + 文 + 操作紧随」的对齐规则，删除各自为政的多余 grid 分支。
4. **详情页顶栏（N-5 / T-3）**：副标题区在分类名旁补当前卡名（用非 heading 元素，正文 `h1` 仍是唯一 heading，不破 `findByRole('heading',{name})` 断言）；底部页码与其 `aria-label` 保持原样（不复制到顶栏，避免 `getByLabelText` 多命中）。
5. **首页微调（N-6 / T-4）**：右大卡底部遮罩带略加高 / label 上沿微让，避开树形插画压字；首页玩法区与底部区之间死白轻收敛（不新增区块、不动信息架构）。

**验收基线**：五类详情 + 故事页在 1440 / 360 两档 `overflowX = 0`；汉字卡详情左栏为笔顺播放器且不再渲染封面 `<img>`；成语卡「中文」按钮不再悬在出处下方空白里；详情页顶栏可见当前卡名。

## 4. 验收标准

1. **汉字卡**：`.detail__stage` 内含 `role="region" name="笔顺演示"`，且 stage 内**不出现**卡片封面 `<img>`（`characters-yi` / `characters-shou` 实测）；「看笔顺」按钮仍在（可访问名不变）。
2. **成语卡 / 古诗卡**：1440 下左主视觉与右文字块视觉基线一致（CDP 目检），`actions` 紧随内容、无大片悬空空档；360 单列不受影响。
3. **顶栏**：`#/card/animals-cat` 顶栏含文本「猫」，且 `findByRole('heading',{name:'猫'})` 仍唯一命中正文标题（顶栏卡名非 heading）。
4. **回归零破坏**：`cards.test.tsx` 既有断言（`第 N 张，共 M 张` 页码、`返回卡片列表`、English 按钮显隐、成语 `region name="成语释义与用法"`、笔顺 `region name="笔顺演示"`）全部继续通过；普通卡 / 故事卡观感不回退。
5. **首页**：右大卡「进阶」文字不被插画压住；三档 `overflowX = 0` 维持。
6. 五道门禁全绿；主 chunk gzip ≤ 197.58、CSS gzip ≤ 9.2（预算风险见技术方案 §4，先删后加）。

## 5. 本版不做

1. **不动功能与数据**：朗读 / 收藏 / 认识 / 翻页 / 连播 / 笔顺播放逻辑、`Card` 实体、路由表、`SEED_VERSION`、`schemaVersion` 全部不变。
2. **不重出图**：汉字卡不再显示封面图 ≠ 删除封面资产（分类墙卡片仍用），不碰 `prepare-images.mjs`。
3. **不动首页信息架构**：v0.13 / v0.14 刚精修，首页只微调遮罩与留白，不加不减区块。
4. **不动年龄页**：v0.14 的档位 chips / 段头 CTA / auto-fit 碎列治理维持，本版年龄页零改动。
5. **不改管理区 / 搜索 / 收藏 / 复习 / 听音选图 / 设置等其余页面**。
