## 1. 需求背景与目标

### 1.1 背景

v0.1 解决的是「看图认词」：一张卡一个词，孩子指认、跟读、翻下一张。但 2–5 岁孩子更爱听**有情节**的东西——「后来呢？」是他们的口头禅。认知卡片只能停在词语层，接不住「后来」。

需求方明确要求：**加入少儿故事，至少 50 个，图文并茂**。

### 1.2 目标

| 目标 | 衡量方式 |
| --- | --- |
| S-G1 从一个词走到一个故事 | 故事卡详情 → 点「开始阅读」≤ 1 次点击进入故事页 |
| S-G2 一页读完，不用翻 | 整个故事（6 段正文）在同一页呈现，配一张综合插图，页面可纵向滚动，无需翻页 |
| S-G3 故事讲完有收束 | 正文下方给出寓意；顶部「返回详情」，不出现「翻不动」的死胡同 |
| S-G4 内容成体系 | 50 个故事，四个主题组：童话 20 / 生活习惯 15 / 情绪社交 10 / 自然认知 5 |
| S-G5 与既有能力一致 | 朗读、展示模式、导入导出、存储降级全部复用，不重复造 |

### 1.3 与 v0.1 的关系

v0.2 **不推翻** v0.1 的任何口径：卡片仍是单一 `Card` 实体，故事是第三种 `kind`（与 `object` / `character` / `poem` 并列），新增字段全部**可选**，`schemaVersion` 保持 1、老数据零迁移。

## 2. 用户故事与验收标准

### US-S1 浏览故事分类（P0）

作为家长，我希望在一处看到全部故事，并按主题挑一个，以便按当天心情或育儿需要选择。

- Given 打开首页，Then 出现第 17 个分类「故事」，封面为绘本风格，数量显示「50 张」。
- Given 进入 `/c/stories`，Then 顶部显示四个组筛选条（童话 / 生活习惯 / 情绪社交 / 自然认知）+「全部 50」。
- Given 未选组，Then 每页 12 张、共 5 页，分页条显示「第 1 / 5 页」。
- Given 选「生活习惯」，Then 只剩 15 张（2 页），并回到第 1 页。
- Given 故事卡在卡片墙上，Then 除标题外带「绘本故事」标识，孩子能区分「这是可以讲的故事」。

### US-S2 故事详情（P0）

作为家长，我希望点开故事先看到综合插图与一句话简介，再决定是否开讲。

- Given 在卡片墙点「三只小猪」，When 进入 `/card/stories-three-pigs`，Then 单屏展示：综合插图、标题「三只小猪」、拼音、英文、一句寓意，以及主按钮「开始阅读」。
- Given 点「开始阅读」，Then 进入 `/story/stories-three-pigs`，整篇故事一次性呈现。
- Given 展示模式为「英文」，Then 标题与寓意显示英文，故事正文仍为中文（正文不翻译，保持故事语感）。
- Given 图片加载失败，Then 显示首字占位块，标题与按钮仍可用。

### US-S3 一页读完（P0）

作为家长，我希望整个故事在一页里讲完，不用一边念一边点翻页。

- Given 进入故事页，Then 先图后文：窄屏自上而下（一张综合插图 4:3 → 6 段正文 → 寓意），宽屏为图左文右两栏。
- Given 窄屏（手机 / 平板竖屏），Then 单列排布：综合图严格 4:3、宽度随视高收窄并居中，正文不足时可纵向滚动。
- Given 宽屏（桌面 / 平板横屏，宽 ≥ 780px 且高 ≥ 520px），Then 两栏排布：图在左栏撑满、正文/寓意/按钮在右栏，一屏读完不需要滚动。
- Given 页面加载完成，Then **不出现**「上一页 / 下一页」按钮、页码（「第 x / 6 页」）与进度圆点。
- Given 刷新页面或分享链接，Then 直接回到同一篇故事（旧链接带 `?page=n` 也能打开，参数忽略）。

### US-S4 故事朗读（P0）

作为幼儿，我希望点一下就有人把整篇故事念给我听。

- Given 支持中文语音，When 点「读整篇」，Then 按顺序朗读全部 6 段正文。
- Given 进入故事页且开启了「进入即朗读」，Then 自动朗读整篇。
- Given 浏览器无语音，Then 按钮禁用并提示，阅读功能不受影响。

### US-S5 返回（P0）

作为用户，我希望退出后能回到刚才的分类与页码，孩子想听下一个不用重找。

- Given 从 `/c/stories?group=story-habit&page=2` 进入故事再返回，Then 回到同一分组同一页。
- Given 在故事页点返回，Then 回到故事详情页（`/card/:id`），而不是直接跳出分类。
- Given 在故事页按 Esc，Then 与点返回行为一致。

### US-S6 管理区编辑故事（P1）

作为家长，我希望自己也能加一个故事，用孩子的名字当主角。

- Given 在卡片管理点「新建卡片」并选类型「故事绘本」，Then 表单显示：标题、拼音、英文、寓意、正文段落（一行一段）。
- Given 正文段落少于 4 行或超过 8 行，When 保存，Then 拒绝并提示「故事需要 4–8 段」。
- Given 保存成功，Then 故事出现在「故事」分类末尾，可正常打开；综合图按 `assets/images/stories/{id}/cover.webp` 约定取图，缺失时显示占位块（不报错）。
- Given 编辑已有故事，Then 逐行文字可改，段数变化只影响段落数量。

## 3. 交互与视觉约束

| 约束 | 说明 |
| --- | --- |
| 一页读完 | 整个故事（4–8 段）在同一页由上到下排布，不设页码、不设翻页交互 |
| 一张综合图 | 每个故事 1 张横版插图（480×360，4:3），画面同时容纳该故事的主要角色（最多 3 个主体） |
| 主体画风 | 主体与背景**同一套扁平插画语言**：同色板、无描边、圆角、统一眼睛与微笑，脚底带落地阴影；**不得使用 emoji 字形或单色剪影**；同一张图内最多三个尺寸位次，保证主次分明 |
| 可辨识度 | 插图在卡片墙缩略图（约 300px 宽）下必须能认出主体：关键轮廓用实心形状或 ≥ 2.6px 描边（< 3px 的细线在缩略图上会整条消失）；浅色主体必须有深一档的同色描边，否则在奶油底上成“虚影” |
| 全站一致 | 故事图、实物卡、诗词卡三处共用同一套“实色形状 + 深一档描边”画法，只换调色（故事=彩色扁平、卡片=渐变天彩色扁平、诗词=宣纸底单色分层墨）；任何分类不得单独回到 emoji 或单色剪影 |
| 物种可辨 | 同类主体（尤其是动物）不能只靠换色区分：每个物种至少在一项**轮廓或身份件**上与邻居不同（体型/腿长/耳型/吻部/项圈/四肢花纹/专属配件），无法做到的（长脸、长颈、长鼻）一律另画侧身，不得继续加参数 |
| 同框比例 | 同一画面内的主体共用一条地面线，腿身比、头身比必须落在同一档位区间：不得出现“单看卡片正常、放进绘本与兽类/人物同框就失衡”的主体；四肢必须落在躯干轮廓内 |
| 正文排版 | 每段独立成行，字号 `clamp(17px, 2.4vh, 21px)`、行高 1.75、段间距约 10px，不用大字号抢图片 |
| 屏幕适配 | 宽屏（≥ 780px 且高 ≥ 520px）图左文右两栏，图占满左栏；窄屏单列，图宽 100%、上限 `calc(58vh × 4 / 3)` 且居中——容器与画面同为 4:3，不得出现两侧露底色的窄图 |
| 触控尺寸 | 「读整篇 / 返回」按钮 ≥ 48px 高；不做细小的页码点 |
| 动效 | 仅进入淡入（`--motion-fast`），尊重「减少动效」设置 |
| 安全区 | 故事页可纵向滚动，底部留 `--safe-b`，不遮挡寓意与按钮 |

## 4. 内容规范

### 4.1 规模与配比

| 组 | 数量 | 说明 |
| --- | --- | --- |
| 童话改编 | 20 | 三只小猪、小红帽、龟兔赛跑、拔萝卜、丑小鸭、小马过河、小猫钓鱼、小蝌蚪找妈妈、猴子捞月、乌鸦喝水、狐狸和乌鸦、守株待兔、井底之蛙、亡羊补牢、狼来了、雪孩子、渔夫和金鱼、金斧头、小壁虎借尾巴、咕咚来了 |
| 生活习惯 | 15 | 刷牙、洗手、收玩具、早睡、好好吃饭、喝水、穿衣服、上厕所、排队、分享、不挑食、过马路、垃圾回家、整理书包、上学不迟到 |
| 情绪社交 | 10 | 生气、怕黑、想妈妈、抢玩具、说对不起、交朋友、被拒绝、输了不哭、等一等、关心别人 |
| 自然认知 | 5 | 种子发芽、四季、雨从哪来、月亮变圆、蚂蚁搬家 |
| 合计 | **50 个 × 6 段 = 300 段文本 + 50 张综合插图** | |

### 4.2 文案纪律

1. **一段一句话**，每段 ≤ 30 字，主语明确（谁 + 做了什么），6 段连起来是一个完整故事。
2. **白描优先**：写孩子看得见的动作与声音，不写抽象情绪词（「他心里很难过」→「他的眼睛红红的」）。
3. **正向收束**：不说教、不恐吓；结局给出可行做法（「小手洗一洗」而非「细菌会生病」）。
4. **经典改编**：保留人物与关键情节，去掉血腥与惩罚性桥段（狼被赶走、猎人来帮忙，不写解剖式结局）。
5. **拼音与英文**：标题带调拼音；英文 ≤ 3 词（如 `Three Little Pigs`）。
6. **插图与故事对得上**：每段声明 `scene` 与 `subject` 作为分镜信息，脚本聚合全书主体生成 1 张综合图，不允许图文错位。
7. **画风一致**：主体只能从出图脚本已注册的画师与主体规格中选取（小兽 / 人物 / 鸟 / 鱼 / 蛙 / 昆虫 / 植物 / 天空 / 物件），色板统一走脚本内置色板；新增主体必须先注册，不得直接贴 emoji。

### 4.3 字段

| 字段 | 类型 | 约束 |
| --- | --- | --- |
| `kind` | `'story'` | 新增枚举值 |
| `pages` | `{ text, image? }[]` | 4–8 段，种子统一 6 段；`text` ≤ 60 字（种子自律 ≤ 30）；`image` 为可选旧字段，新种子不写 |
| `moral` | `string?` | 一句寓意，≤ 60 字，正文下方与详情页展示 |
| `image` | 卡片图 = **综合插图** | `assets/images/stories/{slug}/cover.webp`（一个故事只此一张） |

## 5. 边界与异常

| 场景 | 处理 |
| --- | --- |
| 旧链接带 `?page=n` | 忽略该参数，直接展示整篇故事，不报错 |
| 故事 `pages` 为空（脏数据） | 故事页显示空态「这个故事还没有内容」，含返回按钮 |
| 自建故事无综合图 | 显示首字占位块 + 分类色底，正文照常 |
| 只读模式（存储不可用） | 可正常阅读全部内置故事，管理区入口照旧禁用 |
| 导入含 `pages[].image` 的旧文件 | 字段可选，结构校验通过即可导入 |
| 段落多、屏幕矮 | 单列下正文自然滚动，不挤压图片区（图随视高收窄，比例与位置不变） |

## 6. 明确不做（Out of Scope · v0.2）

| 项 | 原因 |
| --- | --- |
| 每页一张配图 | 需求方明确「故事在一页，配一个综合的图就行」；逐页配图需 300 张且图文对齐成本高 |
| 翻页动画 / 音效 / 自动翻页 | 会显著增加包体与调试成本，单页阅读也不需要 |
| 逐页配音（人声） | 依赖 TTS 已够用，人声录制成本与授权风险高 |
| 分支剧情 / 互动选择 | 属「故事游戏」，与卡片库定位不同 |
| 阅读进度记忆 / 书架 | 记学习轨迹在 v0.1 已列入不做；v0.2 不开口子 |
| 全文翻译英文 | 故事正文保持中文语感，仅标题与寓意做中英 |
| AI 生成插画 | 额度与风格一致性不可控，沿用程序化绘本风 |
| emoji 做故事主体 | emoji 字形由系统字体决定，单色剪影与彩色背景不同族，也无法控制头身比与配色；已由程序化扁平插画取代（见 `NFR/v0.3/技术方案-主体插画.md`） |
