## 3. 验收口径

1. **结构**：首页 DOM 顺序为 `.band-row` → 认物段（`.cat-section` + `.grid-cats`）→ `.cat-row`（字卡 / 诗文 / 绘本三列）；`.cat-tile` 总数仍为 22。
2. **可达性**：分龄卡仍是 2 个链接（`#/age/1-3`、`#/age/3-6`）且都带「N 张适龄」；分类卡的可访问名仍是「名称 N 张卡片」。
3. **窄屏**：360 px 无横向溢出；分龄卡上下堆叠；`.cat-row` 收成单列、横卡不换行、名称不被截断。
4. **不回归**：分龄墙 `/age/:band`、分类页 `?band=`、详情页按龄翻页行为与 v0.8 完全一致（`age.test.tsx` 13 例不动）。
5. **门禁**：五道全绿；CDP 360 / 768 / 1440 / 1826 四档实测 `overflowX = 0`，1440 首屏能看到「认物」段前两行。

## 4. 本次不做

- 不做「按年龄 / 按主题」分段控件（原方案 B）：多一层家长需要理解的交互，等 v0.10 上线后再看数据。
- 不做编辑式首页（原方案 C）：需要推荐逻辑与新数据通道，成本远高于本次目标。
- 不动顶栏入口条：4 个入口按钮（接着看 / 收藏 / 练一练 / 听音选图）保持现状，窄屏横滑 + 右渐隐不变。
- 不重出封面：汉字 / 数字 / 古诗等封面偏素的问题按内容任务另排，不在本次信息架构范围内。
