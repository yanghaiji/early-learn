## 1. 背景与诉求

v0.6.2 把布局与配色改完，需求方追问「还有能规划的嘛 / 继续规划实现」。按改版后的现状核查，暴露出三处与「809 张卡片」规模不匹配的地方：

| 核查项 | 改版后现状 | 问题 |
| --- | --- | --- |
| 前台搜索 | **没有**。只有管理区 `CardAdmin` 有搜索框 | 家长想找「苹果」只能先猜它在哪个分类，逐格翻 |
| 安装 / 离线 | **没有** manifest 与 Service Worker，`public/` 下只有 `assets/` | 文案写着「断网也能用」，但没有任何安装入口，断网后刷新即白屏 |
| 首屏体积 | 单 chunk 613.95 kB（gzip 206.11），超 500 kB 警告线 | `router.tsx` 全部静态 import，管理区与游戏页被算进首屏 |
| 超宽屏 | 1826 px 屏下容器仍 1440，两侧各空 193 px；且顶栏从 24 px 起排、正文从 193 px 起排 | 顶栏与内容**左边缘错位 169 px**，越宽的屏越明显 |

## 2. 需求条目

| 编号 | 需求 | 说明 |
| --- | --- | --- |
| US-V1 | 全局搜索 | 新增 `/search`：一次搜全部 809 张，命中中文 / 英文 / 拼音（可不带声调）/ 标签；结果复用卡片块与分页，URL 带 `?q=` 可分享可返回 |
| US-V2 | 搜索入口 | 首页顶栏与分类页顶栏各加一个放大镜图标；首页顶栏还要能被键盘 `/` 唤出（桌面端） |
| US-V3 | 结果可追溯 | 每张搜索结果标出所属分类名；点开进详情后返回仍回到「那次搜索、那一页」 |
| US-V4 | 安装到桌面 | 提供 `manifest.webmanifest` 与 192 / 512 / maskable 图标；`display: standalone`、`theme_color` 跟随墨绿主色 |
| US-V5 | 离线可用 | Service Worker 预缓存外壳，运行时缓存图片与音频；断网重开仍能浏览已看过的内容，导航回退到缓存的外壳 |
| US-V6 | 首屏瘦身 | 管理区三页、听音选图、故事页、使用说明改懒加载，首屏 JS 明显下降且不出现白屏闪烁 |
| US-V7 | 超宽屏补档 | ≥1700 px 容器放到 1680 px，两侧余白 193 → 73 px；顶栏内容与容器左边缘对齐 |
| US-V8 | 不做破坏性变更 | 不改 `Card` / `Category` 字段、不改既有路由语义、不改 `schemaVersion`、不引第三方 SW 库 |

## 4. 本版不做

1. 不做服务端搜索或索引文件——809 张全量在内存里，前端过滤即够。
2. 不做搜索结果的相关度排序（保持分类内 `sortOrder`），避免「搜出来顺序每次不一样」。
3. 不做后台同步、推送、周期更新等 PWA 进阶能力。
4. 不改管理区搜索（已有，行为与文案均不动）。
5. 不做深色模式、笔顺动画、多龄段模式（仍留在 v0.8 及以后）。
6. 不补「颜色 / 形状 / 数字 / 汉字」四张分类封面的主体图形——这四张 webp 只有底色（1.0–1.3 kB），属 v0.5 素材遗留；本版只动布局与能力，素材另起版本处理。
