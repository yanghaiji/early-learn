# PRD · v0.12 首页段卡改版

> 状态：**已交付**（2026-10-31）。本文是 v0.12 的需求基线，实测回填见 §6。
> 前置：v0.10（首页信息架构：四段分类墙）、v0.11（分类归属纠偏：7 张卡挪类）。
> 需求方原话：「继续 v0.12，然后你再看看感觉这个布局」——v0.11 只修了数据层归属，
> 首页版式问题（L-1~L-4）本版解决。

## 1. 背景与问题清单（2026-10-31 实拍核对）

headless Chrome 实截 360 / 768 / 1440 三档 + CDP 量 DOM，确认四个问题：

| 编号 | 问题 | 实测证据 |
| --- | --- | --- |
| L-1 | **入口与内容量倒挂**：「认物」17 个 tile 铺满 3 整行（1440 档 6×3），但只有 210 张；汉字 321 / 成语 150 / 古诗 50 共 521 张反而挤在底部三小段 | 1440 截图认物区占页面主体；底部字卡/诗文/绘本三列 |
| L-2 | **底部三列段失衡**：绘本列只有 1 张横卡、右侧大片空白；横卡（图左文右）与上方大卡（图上文下）是两套视觉语言 | 1440 截图故事卡右侧空白 |
| L-3 | **颜色/形状封面识别度极低**：两张 tile 近乎空白（渐变底 + 一个弧），因为出图脚本的通用封面只取前 3 张卡的主体画师，而 colors/shapes 的卡主体是特判分支、slug 未登记进 `CARD_SPECS`，取不到就渲染空串 | 768 截图第 3 行两张空 tile；`prepare-images.mjs` coverSvg L1790-1801 |
| L-4 | **360 档首页总高 3043px ≈ 4 屏**，认物 17 tile 双列吃掉约 9 行 | CDP `docHeight = 3043`（360×800 视口） |

360 档**无横向溢出**（CDP：`scrollWidth = clientWidth = 360`，`.grid-cats` 两列各 160px），
v0.10 的溢出结论对本版数据依然成立。

认物 17 类逐类张数（v0.11 纠偏后）：动物 19、水果 16、交通工具 16、蔬菜 13、学校 13、
日常 12、身体 12、天气 12、动作 12、食物 12、小虫子 12、穿戴 12、海洋 11、家人 11、
职业 11、颜色 8、形状 8，合计 **210**。

## 2. 用户故事

| 编号 | 作为 | 我想要 | 以便 |
| --- | --- | --- | --- |
| US-Q1 | 家长 | 首页「认物」收成 **4 张段卡**（动物与植物 / 身边的物什 / 人物与动作 / 自然与概念），点段卡进入该段的分类墙二级页 | 首页不再被 17 个 tile 占满 3 行，各内容板块权重与内容量匹配 |
| US-Q2 | 家长 | 字卡 / 诗文 / 绘本与认物 4 段用**同一套段卡样式**（图上文下），统一排进一个网格 | 消除底部三列空白段与两套视觉语言（L-2） |
| US-Q3 | 家长 | 段卡上能看到**段名、提示语、总张数、所含分类数**；二级页里是该段全部分类 tile（沿用现有 `CategoryTile`） | 不用点进去猜一段里有什么 |
| US-Q4 | 孩子/家长 | 颜色、形状两张**分类封面重绘**（色块排 / 几何形排），补齐识别度 | 分类墙不再出现两张「看起来坏了」的空白卡（L-3） |

  不动 `schemaVersion` / `SEED_VERSION`（与 v0.10 决策 Y 系一脉相承）。

## 3. 页面结构（改版后首页）

1. hero 顶栏：不动。
2. 分龄两档大卡：不动（v0.10 已改版）。
3. **段卡网格**（新）：7~8 张段卡，样式与 `CategoryTile` 同语言（图上文下、右下张数角标），
   但图幅更大一档；1440 四列、768 三列、360 两列。
4. 底部按钮行 / 进度行 / 页脚：不动。

**二级页 `/group/:groupId`**（新）：仿 `AgePage`——返回按钮 + 段名顶栏 +「N 张卡片 · M 个分类」
副标题 + 该段分类墙（`grid-cats` + `CategoryTile`）。非法 `groupId` 走空态；
「更多」段只列家长自建分类。

### 首页高度预算

改版后首页 = 顶栏 + 分龄 2 卡 + 段卡 8 张（360 两列 4 行）+ 底部行。
360 档目标 **≤ 2000px**（现 3043，L-4 减约 1/3）。

## 4. 验收标准

1. 首页不再出现 17 个认物分类 tile；出现且仅出现 7 张内置段卡（有兜底内容时 +1）。
2. 每张段卡可访问名含「段名 N 张卡片」；段卡张数之和 = 809 + 家长自建卡数。
3. 点段卡进入 `/group/:id`，二级页分类 tile 之和与该段张数一致；返回回首页。
4. 非法 `/group/xxx` 显示空态不白屏；`/age/:band`、`/c/:id`、`/card/:id` 行为零回归
   （`age.test.tsx` 13 例不动）。
5. 颜色/形状新封面：色块/几何形主体清晰可辨（人眼验收），其余 657 张图字节不变。
6. 五道门禁全绿；主 chunk gzip ≤ 197.58、CSS gzip ≤ 9.2；360 档首页高 ≤ 2000px 且
   `overflowX = 0`。

## 5. 本版不做

1. **不动卡片数据**：不挪分类、不改种子、`SEED_VERSION` 保持 10（v0.11 已纠偏）。
2. **不做段的管理**：段清单是代码常量，家长不能增删段；自建分类自动落「更多」段。
3. **不重画其余 657 张图**：只补 colors / shapes 两张封面。
4. **不动分龄卡与二级页以下的层级**：分类页、详情页、朗读、收藏全部不变。

## 6. 实现后实测（2026-10-31 回填）
