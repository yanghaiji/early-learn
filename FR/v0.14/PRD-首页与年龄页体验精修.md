## 1. 背景与问题（2026-11-01 v0.13 实现后三档实拍复检）

对 v0.13 交付后的首页与年龄页做 1440 / 768 / 360 三档 CDP 实拍复检，发现：

| 编号 | 问题 | 依据 |
| --- | --- | --- |
| N-1 | **band-hero 封面被 16:9 硬裁、卡过高**：封面原图 1:1（320×320），media 687×387 只能裁上下，主体偏小构图松；单卡高 480px 里图占 387px，两卡吃掉 1440 首屏近半高度 | 探针 `band-hero-card h=480` + `v14-home-1440.png` |
| N-2 | **1440 首页 900px 零余量**：验收线恰好压线，字体缩放或任何一行新增即超屏，脆弱 | 探针 `scrollHeight=900` |
| N-3 | **360 双大卡实际单列堆叠**：`.band-hero` 仅 ≥640px 两列，与 PRD v0.13 §3「360 两列并排（窄卡）」口径不符；两卡 562px + 顶栏把「日常玩法」完全推出首屏（玩法区起点约 800px） | CSS L684-696 + `v14-home-360.png` |
| N-4 | **年龄页无档位切换**：启蒙页想看进阶必须返回首页重点大卡（顶栏只有返回箭头），两档对比要两跳 | `AgePage.tsx` 顶栏实读 |
| N-5 | **段头不像可点的链接**：meta 被 `flex:1 + text-align:right` 推到 1200px 外的行尾，段名与箭头相距悬空；hover 底色仅 8% primary 几乎不可见，家长不知道「点段名看该段全部」 | CSS `.band-group__meta` + `v14-age13-1440.png` |
| N-6 | **段内 6 列网格碎列**：`.grid-cats` ≥1200 固定 6 列是 v0.6.2 为 22 tile 整墙设计的；段分组后段内只有 1~5 类（绘本段仅 1 tile），每段行尾空 1~5 格 | 截图「人物与动作」4 类缺一格、「绘本」1 tile 空 5 格 |

### 关键事实：v0.13 的信息架构方向不需要动

- 年龄双大卡为主视觉 + 日常玩法区收口 + 年龄页按段分组——三档截图确认层级成立，本版**只精修呈现细节，不动信息架构**（不加不减区块、不动路由与数据层）。
- 封面偏淡（`poems.webp` 淡墨山水）在文字压图 + 遮罩方案下自然缓解：遮罩提供对比度底色，**不重出图**（沿用「不重出图」惯例）。

## 2. 用户故事

| 编号 | 作为 | 我想要 | 以便 |
| --- | --- | --- | --- |
| US-S1 | 家长 | 首页年龄大卡的封面**不再被硬裁**、卡片矮一档，文字直接压在图下缘 | 首屏余量 ≥ 100px，字体放大也不掉出首屏 |
| US-S2 | 家长（手机） | 360 窄屏两张大卡**并排一行**，日常玩法区回到首屏可见 | 手机上打开即见「选档 + 玩法」全部主入口 |

| US-S4 | 家长 | 年龄页段头整行**明确可点**：段名旁紧跟「N 类 · 本档 M 张」，行尾有「看全部 →」字样 | 知道点段头能进段页看该段全量 |

## 3. 页面结构（精修点，其余全部不动）

1. **首页 band-hero**：media 比例 ≥640 改 **21:9**（687×294，比现在矮 93px/卡）、<640 改 **4:3 窄卡两列并排**；body 绝对定位压在图下缘，深色渐变遮罩上叠白字（label / tagline / count 三行；360 窄卡藏 tagline 保两行）。封面继续复用 `fruit.webp` / `poems.webp`，零新图。
2. **首页底部区**：不动（家长管理 / 设置 / 说明 / 进度行原样）。
3. **年龄页顶栏**：副标题右侧（宽屏）或下方（窄屏）加两枚档位 chip——`Link` 到 `/age/1-3`、`/age/3-6`，当前档 `is-active`；复用分类页既有 `.chip` 样式，零新 CSS 概念。
4. **年龄页段头**：meta 取消右推，紧跟段名；行尾新增「看全部」+ 右箭头 CTA（主色）；hover 底色加深。整行仍是单个 `Link` 到 `/group/:id`。
5. **年龄页段内网格**：`.band-group .grid-cats` 在 ≥1200 用 `auto-fit, minmax(176px, 260px)` 塌掉空轨；首页 / 分类页 / 年龄页之外的 `.grid-cats` 不受影响。

**高度预算（N-2 验收线）**：1440 首页 hero 顶栏 107 + band-hero 约 294 + 间距 22 + 日常区约 139 + 底部区约 150 ≈ **712-760 ≤ 800**（余量 ≥ 100）。360：band-hero 两列并排后玩法区起点 ≤ 560px（首屏 800 内可见）。

## 4. 验收标准

1. 1440 档首页 `docHeight ≤ 800`（余量 ≥ 100），三档 `overflowX = 0`。
2. 360 档 band-hero 两列并排（`.band-hero__card` 宽约 160px），日常玩法区顶部进入首屏（`play-section` 顶边 ≤ 800px）。
3. band-hero 文字压图可读：遮罩下白字对比度成立；封面加载失败走 `ImageWithFallback` 色底时文字仍可读（遮罩压在色底上）。
4. 年龄页顶栏两枚 chip 可达：当前档 `is-active`、点另一档进 `/age/:band'`；tile 总数 576 / 609 真值断言零回归。
5. 段头整行单链接不变（`/group/:id`），新增「看全部」CTA 不产生嵌套链接。
6. 1440 段内网格无固定 6 列空轨（auto-fit）；首页 / 分类页网格行为零变化。
7. 五道门禁全绿；主 chunk gzip ≤ 197.58、CSS gzip ≤ 9.2（预算风险见技术方案 §4）。

## 5. 本版不做

1. **不动信息架构**：年龄主纲 + 日常玩法区 + 年龄页段分组的层级维持 v0.13，不加新区块。
2. **不重出图**：封面偏淡靠遮罩缓解，不改 `prepare-images.mjs`。
3. **不动数据层 / 路由 / 契约**：`categoryGroups.ts`、`SEED_VERSION`、路由表全部不变。
4. **不动段页 / 分类页 / 详情页**：chips 只加在年龄页顶栏。
5. **不做横滑**：360 两列并排是静态网格（需求方 v0.13 已明确「不要横滑」）。

### 6.1 交付后补丁（2026-11-01，需求方目检反馈「首页不协调」）

需求方在 1440 实拍上反馈 band-hero 双大卡「不协调」，定位为三点：遮罩 `transparent 45% → 45% 黑` 在浅色封面上渲染成横切画面中部的灰雾带、三行文字层级扁平挤左下、压图白字与下方白卡深字两套视觉语汇打架。取纯 CSS 微调（零 DOM / 零 JSX）：

1. 遮罩改「底部实色」`transparent 66% → 78% 黑`，过渡带收窄至下 1/3、上半图透亮，灰雾带消失；
2. label 20 → **22px** 加最轻投影，新增 `::before` 薄荷短线（28×3px，360 隐藏）压住文字块上沿，tagline 提至 92% 白、count 降至 12px/85% 白拉开层级；
3. 为腾 CSS 预算，删 `.sr-only` / `.tap-btn--speaking` / `.toolbar` / `.toolbar__spacer` / `.stack--sm` / `.section-title` / `.divider` 七条 JSX 零引用死规则（−46 行），CSS gzip 反从贴线 9.20 降至 **9.12**（余量 0.08）。

补丁后门禁：typecheck 0 / lint 0 / 408 例全绿 / build 主 chunk 196.53、CSS **9.12** / validate:content ✓；CDP 1440、360 目检确认灰带消失、白字清晰、短线显示（360 隐）、overflowX = 0。版本号仍 0.14.0（归入 v0.14，不升补丁版）。
