## 1. 背景与诉求

需求方在真实使用中提出三条：

1. 「整体调整一下这个布局吧以及点击去的布局 感觉留白太多」——首页与进入分类后的页面，宽屏两侧与卡片下方都有大片空白。
2. 「换一个更好 和更完美的布局颜色」——现有亮蓝主色与低饱和粉彩分类色之间缺少主次，卡片在白色容器里显得发灰。
3. 「在一个合适的位置加入 https://github.com/yanghaiji/early-learn 这个源码地址」——需要一个能被家长找到、又不打扰幼儿浏览的入口。

## 2. 问题诊断（改版前实测）

| 现象 | 根因 |
| --- | --- |
| 1826px 宽屏下内容只占 1180px，两侧各空 ~320px | `.page` 的 `max-width: 1180px` 对所有页面一律生效 |
| 首页分类卡高低不齐，底部堆出空档 | 卡名与英文挤在同一行，`日常用品 / 身体部位` 换行后卡片被撑高 |
| 「12 张」角标压住卡名 | `.cat-tile__count` 绝对定位在卡片右下角，与换行后的标题重叠 |
| 入口条单独占一行，还要吃掉一档高度 | `ProgressEntries` 是 `.page` 内的独立一行，与顶栏标题分离 |
| 成语详情页图片只有 207px、释义块跑到左下角 | `.detail` 两栏网格只给 `stage / words / actions` 定位，`detail__idiom` 未分配网格区域，被自动摆放到第三行左列 |
| 分类页宽屏 12 张卡只铺 1.5 行 | 网格 `auto-fill` 在 1100px 以上给出 7 列，与「每页 12 张」不能整除 |

## 3. 需求条目

| 编号 | 需求 | 说明 |
| --- | --- | --- |
| US-U1 | 列表页铺满、详情页收窄 | 首页 / 分类页 / 收藏页 / 最近页在 ≥1440px 下容器 1440px、边距 24px；详情页容器 1180 → 960px（两栏版式下再窄会把图挤到 400 以下） |
| US-U2 | 首页分类卡等高 | 卡片高度只由封面决定：名称单行（窄屏独占一行）、英文次行、张数改封面右下角角标 |
| US-U3 | 首页顶栏合并 | 标题 + slogan + 四个入口 + 源码入口 + 语言切换收进一条顶栏；窄屏入口条换行到第二行并可横向滑动（右侧渐隐提示） |
| US-U4 | 主色改墨绿 | `--c-primary` 由 `#3E7BFA` 改 `#2F6B57`，`--c-primary-soft` 同步；21 个分类色统一降一档饱和，卡片不再发灰 |
| US-U5 | 分类页每页整行 | 卡片墙列数固定 2 / 4 / 6（按视口），12 张永远填满整行 |
| US-U6 | 成语详情页重排 | 桌面（≥900px）左列为整高图区，右列依次为「四字 + 拼音 / 释义与例句（内部滚动）/ 操作按钮」；图块从 207px 提到 396px |
| US-U7 | 源码入口三处 | 页脚常驻「源码 · GitHub」；首页顶栏 GitHub 图标；设置页新增「关于」区（版本号 + 源码 + 使用说明） |

## 4. 验收标准

| 项 | 标准 | 实测 |
| --- | --- | --- |
| 无横向溢出 | 360 / 1440 两档 `scrollWidth == clientWidth` | 全部相等，越界元素 0 |
| 分类卡等高 | 同一视口下所有 `.cat-tile` 高度一致 | 1440 下统一 205px；360 下统一 178px |
| 卡名不被截断 | 360 下 22 个分类名称完整显示 | 全部完整（中文独占一行） |
| 分类页整行 | 12 张卡填满行数 | 1440 下 6 × 2 行；360 下 2 × 6 行 |
| 详情页图块 | 桌面 ≥ 360px | 396px（1440×900） |
| 源码链接 | 三处均指向同一仓库，新标签打开 | 页脚 / 顶栏 / 设置页各 1 处 |
| 门禁 | typecheck / lint / test / build / validate:content 全绿 | 0 错 / 274 例 / CSS gzip 7.89KB、JS gzip 206.11KB |

## 5. 本版不做

1. 不改任何卡片的图片与音频资产（成语 151 张维持 v0.6.1 成品）。
2. 不新增页面、不改路由、不改 `Card` 契约与 `schemaVersion`。
3. 不动管理区表单与家长门流程（仅设置页新增「关于」一块）。
4. 不引入 CSS 框架或新依赖（源码图标沿用已有的 `lucide-react`）。
5. 不做深色模式（`color-scheme: light` 维持）。
