## 1. 背景与目标

现有 21 个分类覆盖 0–6 岁的「认物、认字、诗词、故事」四类卡片，缺少**词义层面的语言内容**：孩子能认字，却不知道四个字连起来在说什么。本版新增第 22 个分类「成语」，用与诗词同一套水墨语言承载 150 条成语，每条给出释义、两条例句、近义·反义与出处，让「看图—读文—听读—理解—会用」形成一条完整链路。

目标：

1. **能看懂**：每条成语有 6–90 字白话释义，家长一念孩子就懂，不含文言。
2. **能会用**：每条两条例句（一短一长），示范在什么场合说这句话。
3. **能对照**：近义 / 反义各列 1–3 个，形成词族关系，方便家长横向讲。
4. **能溯源**：标注首见文献（书名·篇名），家长讲典故时有据可依。
5. **不破坏既有契约**：`schemaVersion` 仍为 1，旧数据照读；新字段全部可选，旧卡片零改动。

## 2. 范围与口径

### 2.1 数量与分组

| 组 | 主题 | 条数 | 面向 |
| --- | --- | --- | --- |
| 一 | 寓言故事 | 30 | 有情节、可讲故事，最容易被 4–6 岁接受 |
| 二 | 学习求知 | 30 | 上幼儿园后的学习习惯 |
| 三 | 品德修养 | 30 | 与人相处的规矩 |
| 四 | 自然景物 | 30 | 写景、感受季节 |
| 五 | 生活常理 | 30 | 日常判断与做事方法 |
| 合计 | | **150** | |

- 全部为**四字成语**（本版硬约束，见 §8 E-3）；不收三字、五字以上的俗语。
- 分组是**展示分组**，不是新分类：分类仍只有一个「成语」（`categoryId = idioms`）；组信息**不写进卡片数据**，由种子侧内置表 `IDIOM_GROUP_BY_ID`（`idioms-<slug>` → 组 key）决定，与故事按 id 分组同构。
- 难度（`difficulty`）：寓言故事组以 1–2 为主，学习求知 / 品德修养 / 生活常理 2–3 为主，自然景物 1–2 为主；同一组内按「先具体后抽象」排序。

### 2.2 与既有分类的关系

| 项 | 口径 |
| --- | --- |
| 分类 id | `idioms`（新增，第 22 个） |
| 分类名 | 成语（`nameEn`：Idioms） |

| 分类封面 | 生成一张水墨封面（四字印章 + 淡墨山水），随全量出图脚本产出 |

## 3. 数据模型

### 3.1 新卡片类型

`CardKind` 由 `object | character | poem | story` 扩为 `object | character | poem | story | idiom`。

### 3.2 新增字段（全部可选，仅 `kind=idiom` 必填）

| 字段 | 类型 | 必填 | 上限 | 说明 |
| --- | --- | --- | --- | --- |
| `meaning` | string | 是 | 90 字 | 白话释义，6–90 字（词表实测 6–34 字），不出现文言虚词堆叠 |
| `examples` | string[] | 是 | 2–3 条，每条 ≤ 50 字 | 例句；本版逐条写 2 条（第 1 条短、第 2 条长） |
| `synonyms` | string[] | 是 | 1–3 个 | 近义成语，必须也是四字成语 |
| `antonyms` | string[] | 否 | 0–3 个 | 反义成语；确实没有合适反义的写空数组 |
| `citation` | string | 是 | 40 字 | 出处，形如「《论语·为政》」或「现代常用语」 |

- 字段名 `citation` 而非 `source`：`source` 已被图片版权（`ImageSource`）占用，不复用。
- `en`：成语卡**不设英文**，存空串 `''`。为此 `kind=idiom` 放宽非空校验，其余 kind 保持原有「英文必填、≤ 3 词」。
- `pinyin`：四字全拼带声调、空格分隔（如 `shǒu zhū dài tù`）。
- `image`：`assets/images/idioms/<slug>.webp`（子目录名 = `categoryId`，与其余分类一致）。
- `tags`：成语卡**留空数组**；组归属走 `IDIOM_GROUP_BY_ID` 内置表，不用标签充当分组。

### 3.3 兼容性

| 场景 | 行为 |
| --- | --- |
| 旧本地数据（无 idiom） | 正常读取，无迁移动作 |
| 旧导出文件导入 v0.6 | 正常；`idiom` 相关字段缺省即忽略 |
| v0.6 导出文件导入旧版本 | 旧版本 Zod 不认识 `kind=idiom` → 导入被拒并提示格式不正确（已知代价，不修） |
| `schemaVersion` | 保持 1（新增可选字段 + 新 enum 值，属向下兼容扩展） |
| `SEED_VERSION` | 8 → 9，按 id 增量合并种子，不覆盖家长编辑 |

## 4. 展示与交互契约

### 4.1 分类页（`/category/idioms`）

- 卡片用现有 `grid-cards`（每页 12 张），卡片图为水墨四字卡，卡片下方标题即成语本身。
- **组筛选**：复用汉字 / 故事同一套组 chips（`按主题组筛选` 分组控件），组归属由 `IDIOM_GROUP_BY_ID` 内置表决定；选中某组后只列该组 30 条，不选则全部 150 条。
- 分页沿用现有 PAGE_SIZE：150 条 → 13 页，每组 30 条 → 3 页。

### 4.2 详情页（`/card/:id`）

成语版式自上而下：

1. 四字大字标题（`detail__zh`，字号与诗词标题同级）+ 拼音一行（`detail__pinyin`）。
2. **释义**块：`detail__meaning`，字号比例句大一号，行高 1.7。
3. **例句**块：两条例句，每条前缀一个「例」小徽标；左对齐，句与句间距 8px。
4. **近义 / 反义**：两行 chip（`近义：守株待兔 / 坐享其成`），反义为空时整行不出。
5. **出处**：一行小字（`muted`），格式 `出处 · 《韩非子·五蠹》`。
6. 点读：中文按钮读「成语 + 释义」（现有 TTS 文本拼装扩展）；**English 按钮隐藏**（无英文）。

### 4.3 玩法与入口的取舍

| 能力 | 成语是否纳入 | 理由 |
| --- | --- | --- |
| 收藏 | 纳入 | 通用能力，无特殊 |
| 最近浏览 / 接着看 | 纳入 | 同上 |
| 复习队列 `/review` | 纳入 | 「认识 / 不认识」对成语同样有意义 |
| 连播 | 纳入 | 详情页通用动作 |
| 听音选图 `/quiz` | **排除** | 成语卡画面就是四个字，出题等于把答案印在选项上，属于无效题 |
| 搜索 | 纳入 | 按成语、拼音命中；英文为空不参与匹配 |

### 4.4 管理区（`/admin`）

- 新建卡片浮层新增「成语」chip；选中后分类自动切到 `idioms`。
- 表单字段：中文（4 字，`maxLength=4`）、拼音、释义（多行，≤ 90 字，带计数）、例句（一行一条，2–3 行）、近义（逗号分隔）、反义（可空）、出处。
- 「英文」输入框在成语模式下隐藏，提交时 `en` 写 `''`。
- 校验文案与服务端同源（`validateCardRules`）：四字、释义必填、例句 ≥ 2 条、近反义必须是四字成语、出处必填。
- 只读模式（`isReadOnly`）下不可编辑，与其它 kind 一致。

### 5.6 例句撰写规范

每条写 **2 条**例句，落 `examples`：

1. 第 1 条短（8–20 字），家庭 / 幼儿园日常场景，主语用「我 / 你 / 他 / 妈妈 / 老师」，让 4–6 岁能复述。
2. 第 2 条长（20–50 字），出现具体对象与结果，示范因果，例如「他把玩具分给弟弟，真是……」
3. 不用生僻字，不用书面语感叹，不出现文言；例句可以点出成语本身，但不强制。
4. 例句中不出现成人内容（酒、烟、金钱纠纷、暴力）。

## 6. 配图与音频

### 6.1 水墨四字卡（150 张 + 1 张分类封面）

- 画布 320×320，宣纸底 + 细边框，与诗词卡同源（复用 `INK` / `INK_SOFT`）。
- **卡面主体画成语里真实存在的那个东西**：素材侧维护一张意象件库（`IDIOM_MOTIFS`，78 件实物——马 / 牛 / 兔 / 蛙 / 龙 / 蛇 / 井 / 钟 / 靴 / 笔 / 足 / 矛 / 盾 / 炭 / 烛 ……），不画「泛化的山水意境」。守株待兔=树桩 + 兔，井底之蛙=井 + 蛙，画龙点睛=龙 + 笔，郑人买履=靴 + 脚印，画蛇添足=蛇 + 双足。
- 层次：两层淡远山 + 一条地平线（`opacity 0.62`，只做背景，不与主体抢）→ 该成语登记的两件意象 → 四字大字（下部，楷体，字号 62，墨色，字距 6，基线 `y=272`）→ 一条淡墨横线（页脚锚点）。
- 每条成语登记 **2 件意象**（`IDIOM_PROPS`）：落脚件踩地平线（`y=186`）、天象件画上半（`y=108`）；两件左右分开（`x=102 / 218`、`s=1.02`），单件时代码路径居中放大（`x=160`、`s=1.26`）。**意象件未登记 / 未实现即出图报错中止**，与诗词 `POEM_SCENES` 同一口径，并由内容门禁 V6 前置拦截。
- 四字卡不在卡面上写释义：小字在 320px 宽下会糊，释义交给详情页。
- 分类封面：480×360，淡远山 + 山 / 云 / 卷三件意象 + 赭红「成语 · 词典」印章，与其它 21 张封面同版式。

### 6.2 音频

- **不新增预录音频**：成语卡无英文，中文点读走现有 WebSpeech（`zh-CN`），语速沿用设置项。
- 点读文本：`成语 + 释义`（如「守株待兔。守着树桩等兔子撞上来……」），便于孩子听完整意思。
- 现有 659 条音频与 `manifest` 不动；音频门禁改为「只对 `en` 非空的卡要求音频」，成语卡自动豁免。

## 9. 本版明确不做

1. 不做成语接龙、成语填空等新玩法（留给后续版本）。
2. 不做近义 / 反义词条互相跳转（chip 只展示）。
3. 不做典故长文（出处只到「书名·篇名」）。
4. 不做拼音自动标注、不做笔顺。

## 11. 风险与决策

| 编号 | 决策 / 风险 | 结论与理由 |
| --- | --- | --- |
| D-I1 | 成语独立分类，还是并入「汉字」 | 独立分类。成语是词级内容，字段与汉字卡差异大；并进去会让汉字 321 条的分页与分组逻辑变复杂 |
| D-I2 | 拼音轻声与多音字 | 门禁只校验「带调号」，读音准确性靠人工抽查 20 条（如「叶公好龙」这类争议读音已从词表剔除） |
| D-I3 | 150 还是 300 | 本版 150（5×30）；分组表、分页、门禁、出图均按「可增补」设计，后续补词只加数据 |
| D-I4 | 成语进不进听音选图 | 不进。四字卡画面即答案，出题无意义（对应 E-10） |
| D-I5 | 出处写不准的风险 | 只收出处明确的词；无古籍出处的现代常用语标注「现代常用语」（共 11 条），不硬凑书名 |
| D-I6 | 难度偏高的年龄错位 | 分类排最后（`sortOrder=22`）+ `difficulty` 分层，家长按需进入，不打扰首页第一屏 |
| D-I7 | 四字卡的可辨识度 | 卡面只放四字，不放释义；若实测仍难辨，可加分类色点缀（先不做，等实拍反馈） |
| D-I8 | 与「零契约变更」原则的关系 | v0.6 是**扩契约**（新增 enum 值与可选字段），`schemaVersion` 不升、旧数据照读；旧版本读新导出会失败，属可接受代价 |
