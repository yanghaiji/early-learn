## 1. 背景与问题

v0.2.3 的故事综合图由两部分“拼”成：

- **背景**：18 套程序化 SVG 场景（`STORY_SCENES`），扁平、低饱和、圆弧、奶油色天空。
- **主体**：emoji 用 librsvg 渲染成的**单色剪影**（统一暖墨 `#4A4038` + 奶油光晕 `#FFF8EC`）。

需求方反馈：“背景挺好，但狼、猪、房子太不协调，其他配图也一样，能不能像背景一样。”

两个根因：

| 根因 | 表现 |
| --- | --- |
| 画风不同族 | 背景是彩色平涂，主体是单色剪影，中间靠光晕过渡，本质是“贴纸盖在照片上” |
| 造型不可控 | emoji 字形由系统字体决定（粗细、留白、比例），无法与背景的圆角与色板对齐 |

结论：**主体必须由同一套程序化插画语言绘制**，与背景共用色板与圆角，emoji 退出故事图。

---

## 2. 决策（ADR-C1）

| 项 | 决策 |
| --- | --- |
| 结论 | 主体改为**程序化扁平插画**，与背景共用 `CAST_TONES` 色板、无描边、带落地阴影；emoji 不再参与故事图 |
| 理由 | ① 色板可控 → 50 张不漂移；② 造型可控 → 可调头身比、耳形、尾形；③ 零外部资源与授权风险；④ 产物更小（扁平色块比字形压缩率更高） |
| 放弃的方案 | ① 保留 emoji 只加彩色光晕——画风仍割裂；② 引入外部插画素材——授权与风格一致性不可控；③ 调用 AI 生图——额度、一致性、可重复性都不满足 |
| 适用边界 | 故事综合图的“主体”层。实物卡/汉字卡/诗词卡的封面仍走各自管线（emoji 或字形），不在本次范围 |
| 失效条件 | 若将来接入统一插画素材库（含授权），应整体替换本层，而非在其上叠加 |

## 3. 画师分层

主体按“形态族”拆成 9 个画师 + 1 个特例，统一签名 `(spec, { scale }) => svgFragment`，内部坐标约定：**脚底 y = 0，身高约 96**。

| 画师 | 覆盖 | 关键参数 |
| --- | --- | --- |
| `beastArt` | 四足小兽（猪狼狐兔狗猫鼠熊狮猴松鼠马牛羊龟壁虎） | `tone / earIn / ear(long·point·round·big·drop·flop) / tail(puff·stub·wave·bush·curl·hair·tuft·thin·long) / snout / horn / mane / wool / spots / shell` |
| `personArt` | 人物（女孩男孩妈妈奶奶爷爷农民猎人老师渔夫…） | `skin / hair / cloth / style(long·bun·twin·spiky·hat·cap·hunter) / beard` |
| `birdArt` | 鸟（乌鸦麻雀小鸡鸭鸭雏天鹅） | `tone / wing / beak / headBig / beakLong / neck: 'long'` |
| `fishArt` | 鱼（鱼金鱼） | `tone / fin`，不落地 |
| `frogArt` | 青蛙 | `tone` |
| `bugArt` | 昆虫（蚂蚁蝴蝶蜻蜓） | `bug`：`ant` / `butterfly` / `dragonfly` |
| `plantArt` | 植物（草花树种子嫩芽叶子西兰花萝卜木瓜香蕉） | `shape / tone / leaf` |
| `skyArt` | 天空天气（日月星云雨雪花火水滴雪人） | `shape / tone`，内部 `translate(0 -170)` 抬到天上 |
| `thingArt` | 物件（房城堡学校球积木书画盘衣工具桶瓶木石车砖…） | `shape / tone`，新增 cake·cup·bowl·spoon·soap·tooth·brush·shoes·potty·pot·bag·towel·clock·lamp·teddy·meat·axe·umbrella·slide·road·traffic·hands·drawing |
| `tadpoleArt` | 小蝌蚪 | 圆头 + 长尾（emoji 无此字形） |

共用件：

- `castShadow(rx)`：脚底椭圆阴影 `#5C4E3E @0.14`，让主体“站在”草地上而不是飘着。
- `castFace({ cy, r, gap, mouth })`：统一眼睛（含高光）+ 微笑，所有角色同一张脸。
- `earArt` / `tailArt`：按 type 分发，避免每个角色重写。

## 5. 装配链路

```
pages[].subject
   ↓ storyCast()            角色优先于道具，次数 → 首次/最后出场（沿用 v0.2.3）
   ↓ castForScene()         夜景/洞里把太阳换成月亮
   ↓ castBaseY()            落脚线：地面 292 / 飞行 252 / 水中 334 / 天空 296
   ↓ castArtwork()          查 CAST_SPECS → 选画师 → scale = size/96 × boost
   ↓ storySubjectMarkup()   translate(cx, baseY) + castArtwork
   ↓ storyCastMarkup()      主 180 / 双主体 168+140 / 三主体 164+128+128
```

### 5.1 落脚线

| 类型 | baseY | 依据 |
| --- | --- | --- |
| 地面（默认） | 292 | 草地 `groundBand(262~300)`、室内地板 240/250 之下一点，脚踩实地 |
| 飞行（bird/butterfly/dragonfly） | 252 | 悬在草地上方，不落在花丛里 |
| 水中（fish/goldfish/tadpole） | 334 | 沉到水面线（pond 302 / sea 300）以下 |
| 天空（skyArt） | 296 | 画师内部已 `-170`，实际落在 y≈126 |

水面场景额外的整体下移收敛为 `STORY_SUBJECT_DY = { pond: 12, river: 6, sea: 6, cave: 0 }`（v0.2.3 的 74/34/30/8 是按 emoji 基线定的，插画脚底坐标系下会沉底）。

### 5.2 尺度

`scale = size / 96 × boost`：

- `size` 由构图位次给定（主 180 → 配角 128），保证同一张图内主次分明。
- `boost` 只给“内部尺寸本来就小”的物件（勺子 2.0、牙齿 2.2、鞋 1.9、杯子 1.8、伞 1.5…），否则在 128 位次上会缩成小点。角色类默认 1。

### 5.3 光晕退场

v0.2 的 `storyGlow` 是为了让**单色剪影**从彩色背景里浮出来。主体改成彩色插画后，光晕反而变成“贴纸白边”，因此全局关闭（`glowOpacity = 0`），层次交给 `castShadow` 与色板对比。函数保留以便需要时恢复。

## 6. 校验与门禁

`scripts/validate-content.mjs` 的 `parseImageKeys` 改为解析 `CAST_SPECS`：

```js
const castBody = /const CAST_SPECS = \{([\s\S]*?)\n\};/.exec(source)?.[1] ?? '';
const subjects = new Set([...castBody.matchAll(/^  ([a-zA-Z]+): \{ art:/gm)].map((m) => m[1]));
```

因此 `stories.ts` 里出现未注册的 `subject` 会直接门禁失败（不再静默画成占位块）。旧的 `STORY_SUBJECTS`（subject → emoji）已删除。

## 8. 风险与局限

| 项 | 说明 | 处置 |
| --- | --- | --- |
| 造型偏“符号化” | 程序化插画无五官表情、无布褶与毛发细节，近看仍像图标 | 已用头身比（1:1.2 大头）、落地阴影、统一微笑提升“玩偶感”；若后续要更精细，应替换本层而非叠加 |
| 新增 subject 必须注册 | 漏加 `CAST_SPECS` 会在摘要定位到 `thingArt` 默认方块 | `validate-content` 已拦（§6） |
| 夜景主体偏亮 | 深色背景 + 浅色主体对比强 | 已删光晕避免“发光”；保留深色场景 `castShadow` |
| 主体与背景元素重复 | 若某段 `subject` 是 `sun` 而首段场景已画太阳，画面会出现两个太阳 | 只对 night/cave 做 `sun → moon`；其余靠分镜数据自律 |
| 56 处 `CAST_TONES` 引用 | 任一键拼错会渲染成 `fill="undefined"` | 新增前先在 `CAST_TONES` 查键；色板集中在一处，便于脚本自检 |

## 13. v0.3.1 动物辨识度：从“同一模板换色”到“剪影可分辨”的 22 只

### 13.1 问题

v0.3.0 的 22 张动物卡全部走 `beastArt` 一个模板（球头 + 椭圆身 + 两条腿），差异只来自 `tone` 与 7 种 `ear`。结果是 12 只四足兽在缩略图里“看着都是同一个”：熊/猫/狗/兔/羊/猪/牛/马/熊猫 只能靠颜色区分；长颈鹿变成“棒棒糖”，大象鼻子与身体同色糊成灰老鼠。

### 13.2 处置：给模板补“轮廓维度”，跨不过去的主体单独画

| 维度 | 新增参数 | 作用 |
| --- | --- | --- |
| 体型 | `build`：round / slim / long / big / tall | 头身比与身体长宽，决定第一眼轮廓 |
| 腿长 | `legs`：short / long | 矮脚兽与大长腿分开 |
| 耳型 | `ear` 新增 `cat`，`drop` 补内耳 | 猫的尖长耳、狗/牛/羊垂耳 |
| 吻部 | `muzzle` + `noseTone` | 狗/狼/狐/猫/虎/牛 一块浅色吻部与鼻头 |
| 身份件 | `collar` / `teeth` / `whiskers` / `socks` / `hoof` / `blaze` / `forelock` / `ossicone` / `tusks` | 项圈=狗、门牙=兔、白袜=熊猫、蹄子=马、小角=长颈鹿 |
| 花纹 | `stripe` 改横向弧纹，新增 `patches` 大块牛斑 | 虎纹不再长在身体侧边像“贴纸” |

正面模板跨不过去的主体改独立画师（与 `turtleArt` 同一档）：

| 画师 | 原因 |
| --- | --- |
| `elephantArt` | 象鼻必须比身体深一档 + 大扇形耳，否则无论怎么调都像灰老鼠 |
| `horseArt` | 长脸 + 鬃毛 + 马尾只有侧身成立；正面只会得到“戴围脖的熊” |
| `giraffeArt` | 长颈 + 小角 + 颈斑必须侧身，正面是“台灯” |

### 13.3 结果

22 只动物现在有 6 类可分辨剪影：正面厚身（熊/狮/熊猫）、正面瘦高（猫/狗/兔/鼠）、正面长背（猪/牛/羊）、侧身长腿（马/长颈鹿）、侧身拱壳（龟）、非兽类（鸟/鱼/蛙/虫）。故事图里同一套主体同步生效，50 张 cover 复核无悬空/无比例突变。

## 14. v0.3.2 侧身画师的腿身比：从「写死像素」到「随身体推导」

### 14.1 问题

v0.3.1 遗留偏差：马在故事 cover 里腿明显偏长（像踩高跷），卡片单看却正常。核到代码后的结论是——**腿身比与 `scale` 无关**（`<g transform="scale()">` 是整组等比缩放），真正的原因是腿高写成了固定像素：

| 画师 / 模板 | 腿高 | 身体 ry | 腿身比 |
| --- | --- | --- | --- |
| `horseArt`（改前） | 43 | 19 | 2.26 |
| `giraffeArt`（改前） | 51 | 16 | 3.19 |
| `beastArt` 最修长档 tall | 34 | 18 | 1.89 |
| `beastArt` 默认档 round | 28 | 21 | 1.33 |

卡片里马单独出现没有参照；绘本里马与兽类、人物共用同一条地面线，2.26 立刻被比成高跷。所以「卡片正常、cover 偏长」不是两套尺度，而是**同框才暴露的越界比例**。

### 14.2 处置

1. 新增 `SIDE_LEG_RATIO`（elephant 1.4 敦实 / horse 1.6 修长 / giraffe 2.8 长腿即身份），三个侧身画师的腿高一律 `Math.round(ry * 比例)`，身体中心按 `bodyCy = -(legH + ry - 重叠)` 推导（与 `beastArt` 同口径：脚底落 y≈1、身体压住腿根），头、颈、五官、斑点全部改成相对 `bodyCy` / `headCy` 表达，不再散落绝对坐标。
2. 腿位收进身体跨度：马原腿位 x 22~32 而躯干右缘只到 24，长颈鹿腿位 23~32 而躯干右缘 22 —— 最外侧那条腿整个长在轮廓之外，缩略图上就是一根浮着的柱子。改成前后两组（马 -31/-19/-1/11，长颈鹿 -29/-19/-3/7），蹄子路径由同一份 `legXs` 生成，避免再次错位。
3. `elephantArt` 的 1.4 档本就与卡片一致，本次只「去写死」不改观感：推导出的 `legH = 35`、`bodyCy = -46` 与原字面量相同，渲染结果逐像素不变。

### 14.3 结果

马腿身比 2.26 → 1.58、长颈鹿 3.19 → 2.81（长腿仍是长颈鹿的身份，但不再远离模板体系上限），四条腿在卡片与 cover 上都收进躯干。重出 50 张 cover + 22 张动物卡复核：`pony-river`、`lose-game` 两本含马故事的马与同框猴/狗/牛比例协调；大象、长颈鹿卡片风格与改前一致。全量重出 518 个文件，五道门禁全绿。
