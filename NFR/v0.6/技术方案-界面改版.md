## 3. 容器分档（US-U1 / US-U5）

```
.page            1180px   设置 / 说明 / 管理区 / 故事页
.page--wide      1440px   首页 / 分类页 / 收藏页 / 最近页
.detail           960px   卡片详情（两栏时左图右文）
```

- `.page--wide` 只加在四个列表页的 `<main>` 上，其余页面零改动。
- 详情页取 960 而不是 780：≥900px 会切成两栏，780 容器扣掉 padding 与 36px 列距后右列不足 320px，图片被压到 360px 以下，与「图要看得清」直接冲突。
- 窄屏（≤420px）仍由既有 `@media (max-width: 420px)` 把 padding 收到 12/14px，`.page--wide` 同受约束。

## 4. 网格列数

| 网格 | 改法 |
| --- | --- |
| `.grid-cats` | `minmax(176px, 1fr)`，`gap: 18px`；≥1200px 固定 6 列 |
| `.grid-cards` | 默认 `auto-fill minmax(150px,1fr)`；768–1099px 固定 4 列；≥1100px 固定 6 列 |

卡片墙每页 12 张，配 2 / 4 / 6 列即可保证每页都是整行（6×2、4×3、2×6），不再出现「第二行只有两张」的半行空白。分类墙 22 张不追求整除，只保证卡片等高。

## 5. 分类卡结构（US-U2）

改版前：`media` + `h2`（中文与英文 inline）+ 绝对定位 `count`，中文换行即撑高卡片、角标压在文字上。

改版后：

```tsx
<Link className="cat-tile">
  <div className="cat-tile__media">
    <ImageWithFallback />
    <span className="cat-tile__count">{count} 张</span>
  </div>
  <div className="cat-tile__foot">
    <h2 className="cat-tile__name">{name}</h2>
    <span className="cat-tile__en">{nameEn}</span>
  </div>
</Link>
```

- 卡片 `height: 100%`，高度只由封面（4:3）决定，同一行必然等高。
- 名称 `nowrap + ellipsis`；`.cat-tile__foot` 默认纵向（窄屏中文独占一行不被截断），≥560px 改横向（中英同行）。
- 角标改封面右下角 pill，`backdrop-filter: blur(4px)` + 白 84% 底，压在任意插画上都可读。
- 新增 `@media (hover: hover)` 的 `translateY(-2px)` + 主色描边，触屏不触发。

## 6. 首页顶栏（US-U3）

```
<header class="topbar topbar--hero">
  <div class="topbar__brand">标题 + slogan</div>
  <ProgressEntries/>           ← 四个入口
  <div class="topbar__tools">源码图标 + 语言图标</div>
</header>
```

- ≥960px：一条横向，入口条靠右、`flex: 1` 吸收剩余宽度。
- <960px：入口条 `order: 3; width: 100%` 换到第二行，`flex-wrap: nowrap` + `overflow-x: auto` 横向滑动；按钮 `flex: 0 0 auto; white-space: nowrap` 防止被压窄导致文字竖排；`mask-image` 右侧 16% 渐隐作为「还能往右滑」的提示。
- 顶栏 `position: sticky` 未改，但高度从「标题行 + 独立入口条行」降为「标题行 + 56px」，360×780 下由约 150px 降到 112px。

## 7. 成语详情页重排（US-U6）

改版前 grid-areas 只有 `stage / words / actions` 三格，`detail__idiom` 被自动放置到第三行左列 → 释义块跑到图片下方左侧，右列下方空出半屏。

改版后（仅 ≥900px，且仅 `.detail--idiom`）：

```css
grid-template-columns: minmax(0, 1fr) minmax(360px, 1.05fr);
grid-template-rows: auto minmax(0, 1fr) auto;
grid-template-areas:
  'stage words'
  'stage idiom'
  'stage actions';
```

- `stage` 跨三行，`align-self: center`，图块 `height: auto; width: min(100%, 44vh)`，1440×900 实测 396px（改版前 207px）。
- `idiom` 单独占中间一行、`overflow-y: auto`，内容再多也在右列内部滚动，不把图片挤小。
- `actions` 贴底，朗读与「认识 / 不认识」保持在拇指区。
- ≤900px 单列布局完全不变（360 实测四块内容不挤压、无溢出）。

## 10. 决策记录

| ADR | 结论 | 理由 / 放弃的方案 |
| --- | --- | --- |
| U1 | 容器分档而不是全站统一放宽 | 列表页需要横向铺开才能少留白，详情页文字超过 40 字宽就难读；统一 1320 两边都不讨好。放弃「全站 1440」与「保持 1180 只改卡」两个方案 |
| U2 | 主色改墨绿 `#2F6B57` | 与宣纸底、成语水墨卡同族，长期看不刺激；分类色只做「浅色底」，不承担强调职责。放弃「保留亮蓝只修层次」（主次仍缺）与「奶油米 + 砖橙」（详情页大按钮橙度过高，幼儿屏幕冲击大） |
| U3 | 窄屏入口条横滑 + 右渐隐，不换行堆叠 | 换行后 sticky 顶栏会占掉 360×780 的 24%（188px），滚动时一直压着内容；横滑只占一行 56px，且全站 chips 已是同一交互语汇 |

## 11. 风险与后续

| 风险 | 现状 | 后续 |
| --- | --- | --- |
| 窄屏入口条横滑不易发现 | 已加右侧渐隐提示 | 若真机反馈「找不到练一练」，再评估收成「更多」菜单 |
| 分类色降饱和后色差变小 | 21 色仍可区分，且分类靠插画与名称识别 | 若家长反馈「看起来一样」，下一版考虑按分类族分组配色 |
| 详情页 960px 在两栏边界（900–1000px）偏紧 | 该区间右列最小 320px，图片约 360px | 若改成语右列文案更长，优先调 `grid-template-columns` 而不改容器 |
| 1844px 以上超宽屏仍有余白 | 容器上限 1440px 是有意的可读性约束 | 无需处理 |
