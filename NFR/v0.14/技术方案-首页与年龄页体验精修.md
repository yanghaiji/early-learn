## 2. 设计

### 2.1 首页 band-hero：文字压图 + 双档比例（T-S1）

- **≥640**：`.band-hero__media` 比例 `16/9 → 21/9`（687×294）；`.band-hero__body` 改绝对定位压在图下缘（`inset-inline: 0; bottom: 0`），上叠 `linear-gradient(transparent, rgb(0 0 0 / 45%))` 遮罩，三行文字改白色系（label 20px / tagline 13px / count 13px）。卡高 480 → 约 294。
- **<640**：`.band-hero` 从 `1fr` 改**恒两列** `1fr 1fr`（撤 640 断点）；media 比例 `4/3`（161×121）；body 叠层只留 label（14px）+ count（11px），**tagline 隐藏**（`display:none` <640）。
- 结构：`Link > div.band-hero__media(图+遮罩+body)`——body 移进 media 内，`__card` 类名不变；`ImageWithFallback` 不动（色底兜底时遮罩压在色底上仍可读）。
- 遮罩用伪元素还是独立层：直接给 `.band-hero__media::after` 挂渐变（零 DOM 增量）。

### 2.2 年龄页：档位 chips + 段头 CTA（T-S2）

- 顶栏副标题行右侧（`topbar__sub` 改 flex 容器或新增 `.band-switch`）渲染 `<div className="chips" role="group" aria-label="切换年龄档">`：两枚 `Link className="chip"`（当前档 `is-active`），文案 `AGE_BAND_LABEL`（「1–3 岁」「3–6 岁」），链到 `/age/${band}`。窄屏 chips 换行到副标题下方（`.chips` 本身可横滑，天然适配）。
- 段头：`.band-group__meta` 去 `flex:1 / text-align:right` 改紧跟段名；行尾新增 `<span className="band-group__cta">看全部 <ArrowRight/></span>`（`margin-left:auto`、主色）；hover 底色 8% → 12%。整行仍是**单个** `Link`（CTA 是 span 不是嵌套链接，验收 5）。
- `aria-label` 保持 `${group.name} 全部 ${groupTotal} 张卡片`（可访问名不变，测试不破）。

### 2.3 CSS：碎列治理（T-S3）

- `@media (min-width:1200px)` 内新增 `.band-group .grid-cats { grid-template-columns: repeat(auto-fit, minmax(176px, 260px)); }`——空轨塌缩、tile 上限 260px 不巨物化；只作用于年龄页段内，首页 / 分类页 / 收藏页 `.grid-cats` 零影响。
- 增删清单：改 `.band-hero__media`（比例 + ::after 遮罩）、`.band-hero__body`（绝对定位 + 白字）、`.band-hero` 断点合并、`.band-group__meta`（去右推）、`.band-group__cta`（新）、`.band-group__head:hover`（加深）、`.band-switch`（若需要，优先复用 `.chips`）。
- 预算：净新增预计 ≤ 0.05 kB gzip（遮罩与叠层替换掉 body padding / card flex 列布局，近似对冲）；超 9.2 则把 `<640` 的 tagline 隐藏改由 JSX 条件渲染省 CSS。

## 3. 决策台账

| 编号 | 决策 | 理由 | 否决的备选 |
| --- | --- | --- | --- |
| S-1 | band-hero 文字压图 + 21:9（宽屏）/ 4:3（窄屏）双比例 | 需求方选定；卡高 480→294 给 1440 挣出 ~190px 余量，21:9 裁切量比 16:9 小一半 | 左文右图横条（v0.10 方案，年龄档视觉主角地位回落）；重裁封面图（要动生成管线） |
| S-2 | 360 恒两列并排 + 藏 tagline | PRD v0.13 原口径追认；玩法区回到首屏，窄卡放不下三行文字 | 保持单列（N-3 不修）；横滑（需求方已两次明确不要） |
| S-3 | 档位切换用 `.chip` Link 放顶栏，不加全局状态 | URL 唯一事实源（ADR-W2 同口径）；样式零新概念 | Zustand 记「当前档」（多一个事实源，过度设计） |
| S-4 | 段头 CTA「看全部」用 span 挂进既有 Link | 保持整行单链接（a11y 与测试可访问名都不破），语义上「看全部」是段头链接的一部分而非独立入口 | meta 与 CTA 各做一个链接（嵌套/相邻双链接混乱） |
| S-5 | 碎列只在 `.band-group .grid-cats` 局部覆盖 auto-fit | 固定 6 列仍是 22-tile 整墙的正确设计（分类页不破）；auto-fit 塌空轨 + 260px 上限防单 tile 巨物化 | 全站 `.grid-cats` 改 auto-fit（首页分类墙行为回归风险）；段内改 flex-wrap（tile 宽度不齐） |
