## 2. 设计

### 2.1 首页：年龄双大卡 + 日常玩法区（T-R2）

- `.band-row` 升级为 **`.band-hero`**：两张图上文下大卡（视觉主角）——
  media 区 16:9 封面（复用 `BAND_COVER`，不新出图）+ 标题「1-3 岁 · 启蒙」+
  tagline + 「{N} 张适龄 · {M} 段」。1440 / 768 两列，360 两列窄卡。
  M = `groupCategories(categories)` 中该档非空段数（种子数据下两档都是 7）。
- 新增 **`.play-row`**「日常玩法」区：一行 3 张入口卡——
  ① 绘本故事 → `/group/story`（封面 `stories.webp`）；
  ② 听音选图 → `/quiz`（lucide `Headphones` 图标 + 色底）；
  ③ 练一练不熟的 → `/review`（lucide `RotateCcw` 图标 + 色底）。
  零新功能：三张卡只是 `Link` + 文案 + 图标/封面（决策 R-3）。
- **删除**：`grid-groups` 渲染块、`GroupCard` import 与组件文件（决策 R-1/R-2）、
  `.grid-groups` / `.group-card*` CSS 族。
- hero 顶栏 / 底部按钮行 / 进度行 / 只读提示不动。

### 2.2 年龄页按段分组（T-R1）

- `AgePage` 的 `items` 平铺改分组：`groupCategories(categories)` 得 7+1 段骨架，
  段内过滤「本档有卡的分类」（`counts.get(id) > 0`），段内合计为 0 的段整段过滤。
  组合放 UI 层 `useMemo`，不加 domain 新函数（决策 R-4）。
- 每个非空段渲染 `.band-group`：段头是 `Link` 到 `/group/:id`——
  「段名 + 本档 N 张适龄 + 右箭头」；段体沿用 `grid-cats` + `CategoryTile`
  （`countSuffix="张适龄"`、`search=?band=` 透传全部保留，分类页行为零回归）。
- 顶栏副标题「{total} 张适龄卡片」不动；`section-hint` 文案改
  「按主题段浏览，点段名可看该段全部」。空态 / 非法 band 空态不动。
- `GroupPage` 与 `/group/:groupId` 路由零改动（决策 R-1：入口从首页段卡改为
  年龄页段头 + 日常区绘本卡，段页本体保留）。

### 2.3 CSS（T-R3）

- 新增三族：`.band-hero`（2 列网格 + 图上文下卡）、`.play-row`（3 列一行，
  360 收成 3 列小卡或横滑**不采用**——360 三列窄卡，用户明确不要滑动）、
  `.band-group`（段头行 + 复用 `.grid-cats`）。
- 删除：`.grid-groups`、`.group-card` / `.group-card__*` 全族（v0.12 引入）。
- 预算：删段卡族回吐的额度大于新增（段卡带角标/预览行样式更重），
  CSS gzip 预期 ≤ 9.0；实测超预算则按 v0.10 惯例压缩选择器复用。

## 3. 决策台账

| 编号 | 决策 | 理由 | 否决的备选 |
| --- | --- | --- | --- |
| R-1 | 首页去掉段入口，`/group` 路由与 `GroupPage` 保留 | 需求方明确「突出启蒙和进阶」；段页仍有价值（年龄页段头 + 绘本直达是活入口） | 删段页（绘本卡就没落点了） |
| R-2 | 删 `GroupCard.tsx` 组件 | 唯一调用方消失即死代码，与 v0.12 Q-2 删 `row` 同口径 | 留着以防回退（git 里都有） |
| R-3 | 日常区 = 绘本 + 听音 + 复习三卡，全部链现有路由 | 需求方选定口径；零新功能，改动面最小 | 做小游戏（另开内容版） |
| R-4 | 年龄页分组在 UI 层组合 `groupCategories` + band counts，不加 domain 函数 | 两个既有纯函数拼装即可，域层新函数要配独立测试、过度设计 | `bandSections(cards, band)` 域函数 |
| R-5 | band-hero 封面复用 `fruit` / `poems`，不新出图 | v0.10 同口径；两张横条卡升大卡不需要新素材 | 重绘分龄专属插画 |
