## 2. 腾预算（H-3）：把「点进去才用」的模块移出首屏

三步各自实测（每步单独 build）：

| 步骤 | 改动 | 主 chunk gzip | 新增 chunk |
| --- | --- | --- | --- |
| 基线 | T-X9 终点 | 197.57 | — |
| 1 | `HomePage` 里 `DisplayModeSwitch` 改 `lazy` + `Suspense`（点开语言才挂载） | **197.43**（−0.14） | `DisplayModeSwitch` 0.58 kB / gzip 0.42 |
| 2 | 路由里 `SettingsPage`、`AdminGuard` 改 `lazy` | **195.87**（−1.56） | `SettingsPage` 5.27 / 2.07、`AdminGuard` 0.76 / 0.58 |
| 3 | 新增 `features/admin/ui/AdminGateModal.tsx`（`Modal` + `ParentGate` 的薄封装），首页 `lazy` 引用 | **194.90**（−0.97） | `ParentGate` 2.48 / 1.34、`AdminGateModal` 0.26 / 0.19 |

三条实现约定：

1. 首页的两处 `lazy` 都用**局部 `Suspense fallback={null}`**，不用 `AppShell` 那层页面级 `Suspense`：否则点「语言」会把整页换成 `RouteFallback`。
2. `AdminGateModal` 只做封装、不搬逻辑，`markGatePassed` 与 `onPass` 仍在首页——家长门的行为（长按 3s + 算题）不变，`app.test.tsx` / `SettingsPage.test.tsx` 的「家长验证」断言仍成立。
3. 懒加载只改**加载时机**，不改路由语义：`#/settings`、`#/admin` 的挂载点与 fallback 都由 `AppShell` 提供。

## 3. 分组设计（H-2）：纯函数 + 兜底组

新增 `src/domain/services/categoryGroups.ts`：

```ts
export interface CategoryGroupSpec {
  id: string;
  name: string;
  hint: string;
  ids: readonly CategoryId[];
}

export const CATEGORY_GROUPS = [
  { id: 'object', name: '认物', hint: '看图认东西', ids: [/* 17 个实物分类 */] },
  { id: 'character', name: '字卡', hint: '汉字与数字', ids: ['characters', 'numbers'] },
  { id: 'poem', name: '诗文', hint: '古诗与成语', ids: ['poems', 'idioms'] },
  { id: 'story', name: '绘本', hint: '一句一页的小故事', ids: ['stories'] },
] as const;

export const FALLBACK_GROUP = { id: 'more', name: '更多', hint: '管理区新建的分类', ids: [] };

export function groupCategories(categories: readonly Category[]): CategorySection[];
```

三条口径：

- **不改实体**：`Category` 不加 `kind`、`schemaVersion` / `SEED_VERSION` 不动，分组只存在于这个模块里；`id` 一经发布不变，因此清单稳定。
- **必须有兜底**：管理区能新建分类，新分类不在任何内置清单里 → 落 `FALLBACK_GROUP`，否则首页会把它吞掉（这是本方案唯一的「不能错」的点，已单测钉死）。
- **组内顺序按清单**：`filter` 后按 `group.ids.indexOf` 排序。首版直接沿用分类 `sortOrder`，结果「字卡」组里 28 张的数字排在 321 张的汉字前面（见 D-Y2）。
- **空段不渲染**：返回前 `filter(section => section.items.length > 0)`，避免空标题占版面。

## 4. 首页结构（H-1 / H-2）

```
.band-row（2 张分龄大卡：左文右图）
. cat-section 认物   → .grid-cats（2 / 4 / 6 列，17 张）
. cat-section 更多   → 仅当有自建分类（兜底段跟随整行段）
.cat-row             → 三列并排，每列一个 .cat-section + 横卡
   字卡 / 诗文 / 绘本
```

要点：

1. **分龄卡**：`.band-card` 从 `display:flex; flex-direction:column` 改 `display:grid; grid-template-columns: minmax(0,1fr) 88px`（≥640px 时 104px），新增 `.band-card__body` / `.band-card__media`；封面走 `ImageWithFallback` + `eager`（`assets/images/covers/fruit.webp` 与 `poems.webp`，复用已有资产）。`alt=""`，可访问名仍由链接文字提供。
2. **整行段 vs 三小段**：`RAIL_GROUPS = new Set(['character','poem','story'])` 在首页模块里判定（分组语义在领域层，排版在 UI 层）；非 rail 段渲染 `<section class="cat-section"><h2 class="cat-section__title">…</h2><div class="grid-cats">`。
3. **横卡变体**：`CategoryTile` 加可选 `row`，输出 `.cat-tile.cat-tile--row`；DOM 与可访问名不变，`AgePage` / 首页整行段零影响。
4. **段内顺序与标题**：`h2` 内含 `.cat-section__name`（段名）与 `.cat-section__hint`（一句说明），保持「标题 + 说明」在同一行基线上。

## 5. 样式（新增 4 组，共 +0.98 kB raw / +0.16 gzip）

| 选择器 | 作用 |
| --- | --- |
| `.cat-section` / `.cat-section + .cat-section` / `.cat-section__title` / `.cat-section__hint` | 段标题行（17px / 800 + 12px 说明），段间 22px |
| `.cat-row` | `repeat(auto-fit, minmax(220px, 1fr))` + `align-items: start`；768 起固定 3 列，窄屏收成 1 列 |
| `.cat-tile--row` | `display:grid; grid-template-columns: 84px minmax(0,1fr)`；封面 `aspect-ratio: 1/1` |
| `.band-card__body` / `.band-card__media` | 分龄卡左文右图 |

两个必须记住的顺序约束：

- `.cat-tile--row` **必须排在 `.cat-tile` 之后**：两者特异性相同，`display:grid` 会被后面的 `display:flex` 覆盖，rail 卡会被拉成整栏高的巨卡（D-Y6）。
- `.cat-row` 必须 `align-items: start`：否则只有 1 张卡的「绘本」列会被拉伸到与「字卡」列等高（D-Y7）。

## 7. 决策记录

| 编号 | 决策 | 理由 / 放弃项 |
| --- | --- | --- |
| D-Y1 | `SettingsPage` / `AdminGuard` 由静态改懒加载，覆盖 v0.7 ADR-V4「设置页保持静态」 | 主 chunk 只剩 0.01 kB，首页改版必须有额度；两页都是「点进去才用」的低频页，代价是首次进入多一次 chunk 请求（2.11 / 0.58 kB）。v0.7 ADR-V4 的其余分工（首页 / 分类 / 详情等高频页静态）不变 |
| D-Y2 | 段内顺序由分组清单决定，不沿用分类 `sortOrder` | 沿用 `sortOrder` 会把 28 张的「数字」排在 321 张的「汉字」前面；清单顺序是产品口径，可读也可测 |
| D-Y3 | 分组放 `domain/services/categoryGroups.ts` 纯函数，不给 `Category` 加字段 | 加字段要动 `schemaVersion` 与导入导出；22 个内置 id 稳定，派生即可 |
| D-Y4 | 三小段用「三列 + 横卡」，不用「放大竖卡」 | 首版用 `minmax(232px,1fr)` 放大竖卡，1440 下每段右侧仍空 4 列，整页更稀；三列并排后页高从 1981 压到 1368 |
| D-Y5 | 分龄卡封面复用分类封面（水果 / 古诗） | 不新出图、不加资产与预算；后续若要「分龄专属插画」按内容任务另排 |
| D-Y6 | `.cat-tile--row` 必须排在 `.cat-tile` 之后 | 两者特异性相同，`display:grid` 会被后面 `.cat-tile` 的 `display:flex` 覆盖，rail 卡被拉成整栏高的巨卡；已实测（首版就踩了） |
| D-Y7 | `.cat-row` 必须 `align-items: start` | 默认 `stretch` 会把只有 1 张卡的「绘本」列拉到与「字卡」列等高，横卡下方留一片空白 |
