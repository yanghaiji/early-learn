## 2. 设计

### 2.1 汉字卡：笔顺播放器升为主视觉（T-1 / T-T1）

- `CardDetailPage`：`kind === 'character'` 时，`.detail__stage` 内容从「封面 `ImageWithFallback`」改为「`<Suspense fallback={大字}><StrokePlayer/></Suspense>`」（fallback 仍是原 `.detail__char` 大字，未到位不跳版）；`<900` 与 `≥900` 一致（stage 恒放播放器）。
- 右列 `.detail__words` 的 character 分支删掉 `StrokePlayer` 小框，只留 `.detail__pinyin` + `.detail__meta`（画数 / 组词）；`showChinese` 逻辑不变。
- 无笔顺数据兜底：stage 回落到「方块里的静态大字」（复用 `.stroke-player__stage` 样式或 `.detail__char`），仍不渲染空白封面。
- 朗读入口：汉字卡失去「点封面朗读」手势，但 `.detail__speak` 的「中文」按钮保留，功能不减；`aria-label`「朗读 xx」若挂在 stage 上需随封面移除一并迁移或去除，避免悬空 label。
- CSS：新增 `.detail--character .stroke-player`（`--stroke-size` 放大到接近旧封面尺寸，如 `clamp(180px, 46vh, 360px)`）；`main` 类名加 `detail--character`。

### 2.2 成语卡 / 古诗卡：基线对齐 + actions 紧随（T-2 / T-T2）

- **成语卡**：≥900 grid 从三行 `'stage words'/'stage idiom'/'stage actions'`（`1fr` 拉伸致悬空）改为——idiom 内容块与 actions 同处右栏一列（`grid-template-rows` 用 `auto` 而非 `minmax(0,1fr)`，或把 words+idiom+actions 合并为一个右栏流），整组 `align-content:center` 与左图共享居中基线；左图 `align-self:center`。目标：出处下面紧跟「中文」按钮，不留空档。
- **古诗卡**：右列与左图统一垂直居中基线（`.detail--poem .detail__words` 的 `align-self` 与 stage 对齐）；译文 `.detail__translation` 改左对齐 + `max-width` 收窄，去居中换行碎感。
- **五类统一**：普通卡 / 故事卡维持既有 `align-content:center` 两栏（已协调，不动）；poem / idiom 收敛到同一「主视觉居中 + 右栏内容流（文字→操作紧随）」规则，尽量复用同一段 `@media` 而非各写分支。

### 2.3 详情页顶栏补当前卡名（T-3 / T-T3）

- `CardDetailPage` 顶栏 `topbar__sub` 区：分类名后加当前卡名，用 `<span className="topbar__card">` 或 `·` 分隔（**非 heading**，正文 `h1` 仍是唯一 heading → `findByRole('heading',{name})` 不破）。
- 底部 `.toolbar__page`（`aria-label="第 N 张，共 M 张"`）**原样不动**，不把页码搬顶栏也不复制（避免 `getByLabelText` 多命中）。
- 无新增 CSS 概念优先，复用 `.topbar__sub`；如需分隔样式，走内联或既有工具类，控制净新增行数。

### 2.4 首页微调（T-4 / T-T4）

- **H-2 遮罩避让**：右大卡插画压字属 `poems.webp` 构图，微调 `.band-hero__media::after` 底部实色带上沿（`66% → 62%` 略增高）或 `.band-hero__body` 下内距，让 label 落在更深的遮罩区；纯 CSS，不重出图。
- **H-1 底部死白**：轻收敛首页玩法区与底部区之间间距（`.play-section` / 底部区 margin），不新增区块、不动结构；若判定为 AppShell `min-height` 推底的自然留白且改动风险高，则仅登记观察、不强改（守「不过度设计」）。

## 3. 决策台账

| 编号 | 决策 | 理由 | 否决的备选 |
| --- | --- | --- | --- |
| T-1 | 汉字卡详情以 `StrokePlayer` 为左栏主视觉、不渲染封面图 | N-1：封面是低信息占位图且与右列笔顺框「一字两现」；笔顺播放器才是汉字卡真正主视觉，321 字全覆盖恒可用 | 保留封面缩小并置（冗余仍在）；只调尺寸/间距（治标不治本） |
| T-2 | poem / idiom 收敛到「主视觉居中 + 右栏内容流、actions 紧随」的统一两栏骨架 | N-2/N-3/N-4：idiom `1fr` 行悬空、poem 基线错开根因是各行 `align-self`/`1fr` 不一致；统一后视觉语言一致、可删冗余 grid 分支省 CSS | 五类各写各的（现状）；强行一套 grid 模板管所有（poem/idiom 内容高度差异大，居中会把溢出推到滚不到，v0.7 已记坑） |

| T-4 | 首页仅遮罩避让 + 留白轻收敛，判定为自然留白则只登记不强改 | v0.13/v0.14 刚做完首页架构，H-1/H-2 是微调级；过度改版违背「不动信息架构」 | 首页再来一次结构改版（过度设计） |

## 4. 预算与风险

| 风险 | 缓解 |
| --- | --- |
| CSS 余量仅 0.08，统一骨架 + 汉字卡放大播放器可能顶穿 9.2 | 统一 poem/idiom 分支会**删掉**各自为政的 grid 规则，净新增可能为负；仍超则跑孤儿规则扫描删 JSX 零引用死规则（v0.14 补丁先例） |
| 汉字卡 stage 换 `StrokePlayer` 后主 chunk 增 `Suspense` 分支 | `StrokePlayer` 与 `hanzi-writer` 仍懒加载独立 chunk，主 chunk 只多几字节；build 后核对，超 197.58 再挪 |
| 顶栏加卡名引 `findByRole('heading')` / `getByText` 多命中 | 卡名用非 heading（`span`）；新用例用 `within(topbar)` 作用域；跑全量测试定位受影响用例统一修 |
| 移除汉字卡「点封面朗读」手势 | 「中文」朗读按钮保留在 `.detail__speak`，功能不减；仅失去一个冗余入口 |
| poem/idiom 改 `align-content` 后长内容滚不到（v0.7 已知坑） | 内容超容器时不用 `align-content:center` 硬居中，改右栏内部自然流 + `overflow-y:auto` 兜底；CDP 1440/360 目检滚动可达 |
| 首页 H-1 死白若源于 AppShell `min-height` 推底 | 判定为自然留白则只登记观察不强改，避免为凑版面引入新风险 |
